## Core Concepts

All Autumn SDKs are built around three main operations:

### 1. Attach

Subscribe customers to products and plans. The `attach` function handles all purchase flows including:
- New subscriptions
- Upgrades and downgrades
- Plan changes
- Stripe Checkout URL generation

### 2. Check

Verify feature access before allowing actions. Use `check` to:
- Validate if a customer has access to a feature
- Get remaining usage limits
- Enforce feature gates

### 3. Track

Record usage events for metered features. The `track` function:
- Logs feature consumption
- Enforces usage limits
- Powers usage-based billing

## Authentication

All SDKs require authentication using your Autumn API key:

<Tabs>
  <Tab title="Server-side (Secret Key)">
    Use your **secret key** for server-side operations:
    
    ```bash
    AUTUMN_SECRET_KEY=am_sk_test_...
    ```
    
    <Warning>
      Never expose secret keys in client-side code. Secret keys have full access to your Autumn account.
    </Warning>
  </Tab>
  
  <Tab title="Client-side (Public Key)">
    Use your **public key** for client-side operations:
    
    ```bash
    AUTUMN_PUBLIC_KEY=am_pk_test_...
    ```
    
    <Info>
      Public keys are safe to use in browsers and mobile apps. They have limited permissions for customer-scoped operations.
    </Info>
  </Tab>
</Tabs>

## Getting Your API Keys

1. Log in to your [Autumn Dashboard](https://app.useautumn.com)
2. Navigate to **Settings** → **API Keys**
3. Copy your secret key for server-side use
4. Copy your public key for client-side use

<Note>
  API keys are environment-specific. Use test keys during development and production keys in live environments.
</Note>

## Common Patterns

### Customer Identification

All operations require a `customerId` to identify which customer is performing the action:

```typescript
const customerId = "user_123"; // Your internal user/org ID
```

<Tip>
  Use your existing user or organization IDs as customer IDs. Autumn syncs with your authentication system.
</Tip>

### Error Handling

All SDK methods return typed responses with error handling:

```typescript
try {
  const { data } = await autumn.check({
    customerId: "user_123",
    featureId: "api_calls"
  });
  
  if (data.allowed) {
    // Proceed with action
  }
} catch (error) {
  console.error("Autumn API error:", error.message);
}
```
