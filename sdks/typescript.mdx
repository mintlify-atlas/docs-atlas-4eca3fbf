The Autumn TypeScript SDK provides a complete interface for managing billing, subscriptions, and feature access in Node.js and TypeScript applications.

## Installation

<CodeGroup>
```bash npm
npm install autumn-js
```

```bash yarn
yarn add autumn-js
```

```bash pnpm
pnpm add autumn-js
```

```bash bun
bun add autumn-js
```
</CodeGroup>

## Initialization

### Basic Setup

Create an Autumn client instance with your secret key:

```typescript index.ts
import Autumn from 'autumn-js';

const autumn = new Autumn({
  secretKey: process.env.AUTUMN_SECRET_KEY
});
```

### Configuration Options

<ParamField path="secretKey" type="string" required>
  Your Autumn secret key from the [dashboard](https://app.useautumn.com). Starts with `am_sk_`.
</ParamField>

<ParamField path="baseUrl" type="string" default="https://api.useautumn.com/v1">
  API base URL. Override for self-hosted instances.
</ParamField>

<ParamField path="timeout" type="number" default="30000">
  Request timeout in milliseconds.
</ParamField>

### Environment Variables

Store your secret key securely:

```bash .env
AUTUMN_SECRET_KEY=am_sk_test_...
```

<Warning>
  Never commit secret keys to version control. Use environment variables or secret management services.
</Warning>

## Core Operations

### Attach (Subscribe Customers)

Subscribe customers to products and plans:

```typescript billing.ts
const { data } = await autumn.attach({
  customerId: 'user_123',
  productId: 'pro_plan',
  successUrl: 'https://yourapp.com/success',
  cancelUrl: 'https://yourapp.com/pricing'
});

// For new customers, data.url contains Stripe Checkout URL
if (data.url) {
  return { redirectUrl: data.url };
}

// For existing customers, subscription updates immediately
console.log('Subscription updated');
```

#### Attach Parameters

<ParamField path="customerId" type="string" required>
  Your internal user or organization ID
</ParamField>

<ParamField path="productId" type="string" required>
  The product ID to attach
</ParamField>

<ParamField path="successUrl" type="string">
  URL to redirect after successful payment
</ParamField>

<ParamField path="cancelUrl" type="string">
  URL to redirect if user cancels checkout
</ParamField>

<ParamField path="quantity" type="number">
  For seat-based pricing (e.g., number of team members)
</ParamField>

<ParamField path="entityId" type="string">
  Entity ID for multi-entity subscriptions
</ParamField>

### Attach with Quantity

Handle seat-based or quantity-based pricing:

```typescript
await autumn.attach({
  customerId: 'org_456',
  productId: 'team_plan',
  quantity: 5, // Number of seats
  successUrl: 'https://yourapp.com/success'
});
```

### Check (Verify Access)

Check if a customer can access a feature:

```typescript access.ts
const { data } = await autumn.check({
  customerId: 'user_123',
  featureId: 'api_calls'
});

if (!data.allowed) {
  throw new Error('Feature access denied');
}

// Proceed with feature access
```

#### Check Parameters

<ParamField path="customerId" type="string" required>
  Customer ID to check access for
</ParamField>

<ParamField path="featureId" type="string" required>
  Feature ID to check
</ParamField>

<ParamField path="quantity" type="number" default="1">
  Amount to check (for usage-based features)
</ParamField>

<ParamField path="entityId" type="string">
  Check access for specific entity
</ParamField>

### Check with Usage Details

Get detailed usage information:

```typescript
const { data } = await autumn.check({
  customerId: 'user_123',
  featureId: 'api_calls'
});

console.log(`Used: ${data.current_usage} / ${data.limit}`);
console.log(`Remaining: ${data.remaining}`);

if (!data.allowed) {
  return {
    error: 'Limit reached',
    upgradeUrl: '/pricing'
  };
}
```

### Track (Record Usage)

Track feature consumption for metered features:

```typescript usage.ts
// Track single unit
await autumn.track({
  customerId: 'user_123',
  featureId: 'api_calls',
  value: 1
});

// Track multiple units
await autumn.track({
  customerId: 'user_123',
  featureId: 'storage_gb',
  value: 2.5
});
```

#### Track Parameters

<ParamField path="customerId" type="string" required>
  Customer ID recording usage
</ParamField>

<ParamField path="featureId" type="string" required>
  Feature ID being consumed
</ParamField>

<ParamField path="value" type="number" required>
  Amount of usage to record
</ParamField>

<ParamField path="eventName" type="string">
  Optional event name for analytics
</ParamField>

<ParamField path="properties" type="object">
  Additional metadata
</ParamField>

<ParamField path="entityId" type="string">
  Entity consuming the feature
</ParamField>

### Check and Track Pattern

Combine check and track for gated features:

```typescript
async function makeApiCall(customerId: string) {
  // 1. Check if customer has access
  const { data: checkData } = await autumn.check({
    customerId,
    featureId: 'api_calls'
  });

  if (!checkData.allowed) {
    throw new Error('API limit reached');
  }

  // 2. Perform the operation
  const result = await performApiOperation();

  // 3. Track the usage
  await autumn.track({
    customerId,
    featureId: 'api_calls',
    value: 1
  });

  return result;
}
```

## Checkout Flow

### Generate Checkout Preview

Use `checkout` to preview pricing before attaching:

```typescript
const { data } = await autumn.checkout({
  customerId: 'user_123',
  productId: 'pro_plan'
});

if (data.url) {
  // New customer - redirect to Stripe
  return { stripeUrl: data.url };
}

// Returning customer - show preview
return {
  preview: {
    product: data.product,
    total: data.total,
    currency: data.currency
  }
};
```

### Complete Checkout

After user confirms preview, attach the product:

```typescript
// User confirmed the change
await autumn.attach({
  customerId: 'user_123',
  productId: 'pro_plan'
});
```

## TypeScript Types

The SDK is fully typed with TypeScript:

```typescript
import type {
  CheckParams,
  CheckResult,
  AttachParams,
  AttachResult,
  TrackParams,
  Customer,
  Product,
  Invoice
} from 'autumn-js';

const params: CheckParams = {
  customerId: 'user_123',
  featureId: 'api_calls'
};

const { data }: { data: CheckResult } = await autumn.check(params);
```

## Error Handling

All SDK methods throw typed errors:

```typescript
try {
  await autumn.attach({
    customerId: 'user_123',
    productId: 'pro_plan'
  });
} catch (error) {
  if (error.code === 'not_found') {
    console.error('Product not found');
  } else if (error.code === 'payment_required') {
    console.error('Payment method required');
  } else {
    console.error('Unexpected error:', error.message);
  }
}
```

## Framework Integration

### Express.js Middleware

Create middleware for feature access control:

```typescript middleware.ts
import Autumn from 'autumn-js';
import type { Request, Response, NextFunction } from 'express';

const autumn = new Autumn({
  secretKey: process.env.AUTUMN_SECRET_KEY
});

export function requireFeature(featureId: string) {
  return async (req: Request, res: Response, next: NextFunction) => {
    const customerId = req.user?.id;
    
    if (!customerId) {
      return res.status(401).json({ error: 'Unauthorized' });
    }

    try {
      const { data } = await autumn.check({ customerId, featureId });
      
      if (!data.allowed) {
        return res.status(403).json({
          error: 'Feature access denied',
          upgradeUrl: '/pricing'
        });
      }
      
      next();
    } catch (error) {
      return res.status(500).json({ error: 'Access check failed' });
    }
  };
}
```

Usage:

```typescript routes.ts
import { requireFeature } from './middleware';

app.post('/api/generate', 
  requireFeature('ai_generation'),
  async (req, res) => {
    // Feature access verified
    const result = await generateWithAI();
    
    // Track usage
    await autumn.track({
      customerId: req.user.id,
      featureId: 'ai_generation',
      value: 1
    });
    
    res.json(result);
  }
);
```

### Next.js API Routes

```typescript app/api/check-access/route.ts
import Autumn from 'autumn-js';
import { NextResponse } from 'next/server';

const autumn = new Autumn({
  secretKey: process.env.AUTUMN_SECRET_KEY
});

export async function POST(request: Request) {
  const { customerId, featureId } = await request.json();
  
  try {
    const { data } = await autumn.check({ customerId, featureId });
    return NextResponse.json({ allowed: data.allowed });
  } catch (error) {
    return NextResponse.json(
      { error: 'Check failed' },
      { status: 500 }
    );
  }
}
```

## Best Practices

<AccordionGroup>
  <Accordion title="Use Environment Variables">
    Always store API keys in environment variables:
    
    ```typescript
    const autumn = new Autumn({
      secretKey: process.env.AUTUMN_SECRET_KEY
    });
    ```
  </Accordion>

  <Accordion title="Implement Retry Logic">
    Add retry logic for transient failures:
    
    ```typescript
    async function checkWithRetry(params: CheckParams, retries = 3) {
      for (let i = 0; i < retries; i++) {
        try {
          return await autumn.check(params);
        } catch (error) {
          if (i === retries - 1) throw error;
          await new Promise(resolve => 
            setTimeout(resolve, 1000 * (i + 1))
          );
        }
      }
    }
    ```
  </Accordion>

  <Accordion title="Cache Feature Checks">
    Implement caching to reduce API calls:
    
    ```typescript
    const cache = new Map<string, { allowed: boolean, expires: number }>();
    
    async function checkWithCache(customerId: string, featureId: string) {
      const key = `${customerId}:${featureId}`;
      const cached = cache.get(key);
      
      if (cached && cached.expires > Date.now()) {
        return { data: { allowed: cached.allowed } };
      }
      
      const result = await autumn.check({ customerId, featureId });
      cache.set(key, {
        allowed: result.data.allowed,
        expires: Date.now() + 60000 // 1 minute
      });
      
      return result;
    }
    ```
  </Accordion>

  <Accordion title="Handle Webhooks">
    Set up webhook handlers for real-time updates:
    
    ```typescript
    app.post('/webhooks/autumn', async (req, res) => {
      const event = req.body;
      
      switch (event.type) {
        case 'customer.subscription.updated':
          // Clear cache, notify user
          break;
        case 'customer.feature.limit_reached':
          // Send notification
          break;
      }
      
      res.status(200).send('OK');
    });
    ```
  </Accordion>
</AccordionGroup>
