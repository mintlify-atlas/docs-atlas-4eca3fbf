## Overview

The `/attach` endpoint subscribes customers to products, granting them access to features and starting billing. Use attach to programmatically manage subscriptions from your backend.

## When to Use Attach

Use the attach endpoint when:

- **Customer has payment method** - They've already provided payment information
- **Internal provisioning** - Admin dashboard or support tools  
- **Free plans** - No payment required
- **Trial activation** - Starting trial periods
- **Upgrades/downgrades** - Changing existing subscriptions

<Info>
For new customers without payment info, use the [Checkout API](/api-reference/core/checkout) instead to collect payment details.
</Info>

## Basic Product Attachment

<Steps>
  <Step title="Attach a product to a customer">
    Call the `/attach` endpoint with customer and product IDs:

    ```typescript
    import { Autumn } from '@useautumn/sdk';

    const autumn = new Autumn({ apiKey: process.env.AUTUMN_API_KEY });

    const result = await autumn.attach({
      customer_id: 'customer_123',
      product_id: 'pro_plan'
    });

    console.log(result.customer_id); // "customer_123"
    ```
  </Step>

  <Step title="Handle the response">
    Check if the attachment was successful:

    ```typescript
    if (!result.required_action) {
      // Product attached successfully
      console.log('Subscription activated');
      
      // Provision access via webhooks, not directly here
    }
    ```
  </Step>

  <Step title="Handle payment requirements">
    If payment is required, redirect to the checkout URL:

    ```typescript
    if (result.payment_url) {
      // Redirect customer to complete payment
      return {
        message: 'Payment required',
        redirect_url: result.payment_url
      };
    }
    ```
  </Step>
</Steps>

## Upgrading Plans

Change a customer's subscription to a higher tier:

```typescript
// Customer currently on 'starter_plan'
const result = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'pro_plan'
});

// Autumn automatically:
// - Prorates the upgrade
// - Charges the difference  
// - Updates feature access
// - Maintains the billing cycle
```

<Tip>
Upgrades are prorated by default using `billing_behavior: 'prorate_immediately'`.
</Tip>

## Downgrading Plans

Move a customer to a lower tier:

```typescript
const result = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'starter_plan',
  billing_behavior: 'next_cycle_only'
});

// Downgrade takes effect at end of billing period
// Customer keeps pro access until then
```

## Custom Product Configuration

Attach a product with custom items and quantities:

```typescript
const result = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'team_plan',
  items: [
    {
      feature_id: 'seats',
      type: 'quantity',
      quantity: 10,
      price: {
        unit_amount: 1000, // $10 per seat
        currency: 'usd'
      }
    },
    {
      feature_id: 'storage_gb',
      type: 'metered',
      price: {
        unit_amount: 500, // $5 per GB
        currency: 'usd'
      }
    }
  ]
});
```

## Scheduling Products

Schedule a product to start at a future date:

```typescript
const result = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'pro_plan',
  plan_schedule: {
    start: 'future',
    start_date: Math.floor(Date.now() / 1000) + 86400 * 30 // 30 days from now
  }
});

// Product will activate in 30 days
```

## Forcing Immediate Activation

Enable a product immediately without waiting for payment:

```typescript
const result = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'enterprise_plan',
  enable_product_immediately: true,
  invoice: true,
  finalize_invoice: true
});

// Product is active immediately
// Invoice is created and finalized
// Payment will be collected via default payment method
```

## Redirect Behavior

Control when customers are redirected to checkout:

```typescript
// Always redirect to checkout (default)
const alwaysRedirect = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'pro_plan',
  redirect_mode: 'always',
  success_url: 'https://example.com/success'
});

// Only redirect if payment method required
const ifRequired = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'pro_plan',
  redirect_mode: 'if_required'
});

// Never redirect (API-only flow)
const never = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'pro_plan',
  redirect_mode: 'never'
});
```

## Creating Separate Subscriptions

Create a new billing subscription instead of adding to existing:

```typescript
const result = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'addon_service',
  new_billing_subscription: true
});

// Creates separate subscription with its own billing cycle
```

## Entity-Scoped Products

Attach products scoped to specific entities:

```typescript
// Attach a product for a specific workspace
const result = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'workspace_pro',
  entity_id: 'workspace_456'
});

// Each workspace can have its own subscription
const workspace2 = await autumn.attach({
  customer_id: 'customer_123',
  product_id: 'workspace_starter',
  entity_id: 'workspace_789'
});
```

## Admin Provisioning Pattern

Implement admin tools to manage customer subscriptions:

```typescript
import { Request, Response } from 'express';

// Admin endpoint to provision subscriptions
app.post('/admin/subscriptions/attach',
  requireAdmin,
  async (req: Request, res: Response) => {
    const { customer_id, product_id, reason } = req.body;

    try {
      const result = await autumn.attach({
        customer_id,
        product_id
      });

      // Log admin action
      await auditLog({
        action: 'attach_product',
        admin: req.user.id,
        customer: customer_id,
        product: product_id,
        reason
      });

      res.json(result);
    } catch (error) {
      res.status(500).json({ error: error.message });
    }
  }
);
```

## Self-Service Upgrades

Let customers upgrade themselves:

```typescript
app.post('/api/upgrade',
  authenticate,
  async (req: Request, res: Response) => {
    const customerId = req.user.autumnCustomerId;
    const { plan_id } = req.body;

    // Validate plan is an upgrade
    const currentPlan = await getCurrentPlan(customerId);
    if (!isUpgrade(currentPlan, plan_id)) {
      return res.status(400).json({ error: 'Invalid upgrade path' });
    }

    try {
      const result = await autumn.attach({
        customer_id: customerId,
        product_id: plan_id
      });

      if (result.payment_url) {
        // Payment info needed
        return res.json({
          checkout_required: true,
          checkout_url: result.payment_url
        });
      }

      // Upgraded successfully
      return res.json({
        success: true,
        message: 'Plan upgraded successfully',
        new_plan: plan_id
      });
    } catch (error) {
      return res.status(500).json({ error: error.message });
    }
  }
);
```

## Error Handling

Handle common attach errors:

```typescript
try {
  const result = await autumn.attach({
    customer_id: 'customer_123',
    product_id: 'pro_plan'
  });

  return result;
} catch (error) {
  if (error.code === 'customer_not_found') {
    // Create customer first
    await autumn.customers.create({
      id: 'customer_123',
      email: 'user@example.com'
    });
    
    // Retry attach
    return await autumn.attach({
      customer_id: 'customer_123',
      product_id: 'pro_plan'
    });
  }

  if (error.code === 'product_not_found') {
    return {
      error: 'Invalid plan selected'
    };
  }

  // Unknown error
  console.error('Attach failed:', error);
  throw error;
}
```

## Webhooks After Attach

Always provision access via webhooks:

```typescript
app.post('/webhooks/autumn', async (req, res) => {
  const event = verifyWebhook(req);

  if (event.type === 'customer.product.created') {
    const { customer_id, product_id, status } = event.data;

    if (status === 'active') {
      // Provision access immediately
      await enableFeatures(customer_id, product_id);

      // Send welcome email
      await sendEmail({
        to: await getCustomerEmail(customer_id),
        template: 'subscription_started',
        data: { product_id }
      });
    }
  }

  if (event.type === 'customer.product.updated') {
    // Handle upgrades/downgrades
    await updateFeatureAccess(event.data.customer_id);
  }

  res.json({ received: true });
});
```
