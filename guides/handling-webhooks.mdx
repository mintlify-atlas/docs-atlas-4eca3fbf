## Overview

Webhooks notify your application when events occur in Autumn. Use them to provision access, handle cancellations, process payments, and keep your system in sync with billing events.

Autumn uses [Svix](https://www.svix.com/) for reliable webhook delivery with automatic retries, signature verification, and a dashboard for monitoring.

## When to Use Webhooks

Webhooks are essential for:

- **Provisioning access** - Enable features when customers subscribe
- **Revoking access** - Remove access when subscriptions end
- **Handling payments** - React to successful or failed payments  
- **Syncing data** - Keep your database in sync with billing changes
- **Sending notifications** - Email customers about billing events
- **Triggering workflows** - Start internal processes based on events

## Setting Up Webhooks

<Steps>
  <Step title="Create a webhook endpoint">
    Create an endpoint in your application to receive POST requests:

    ```typescript
    import { Webhook } from 'svix';
    import { Request, Response } from 'express';

    app.post('/webhooks/autumn', async (req: Request, res: Response) => {
      const rawBody = JSON.stringify(req.body);
      const headers = req.headers;

      // Verify webhook signature
      const wh = new Webhook(process.env.AUTUMN_WEBHOOK_SECRET!);
      
      try {
        const event = wh.verify(rawBody, {
          'svix-id': headers['svix-id'] as string,
          'svix-timestamp': headers['svix-timestamp'] as string,
          'svix-signature': headers['svix-signature'] as string
        }) as WebhookEvent;

        // Process the event
        await handleWebhookEvent(event);

        return res.json({ success: true });
      } catch (err) {
        console.error('Webhook verification failed:', err);
        return res.status(400).json({ error: 'Invalid signature' });
      }
    });
    ```
  </Step>

  <Step title="Configure in dashboard">
    Add your webhook URL in the Autumn dashboard:

    1. Navigate to **Settings** → **Webhooks**
    2. Click **Add Endpoint**
    3. Enter your URL: `https://yourapp.com/webhooks/autumn`
    4. Select events to receive (or choose "All events")
    5. Copy your webhook signing secret
    6. Save the secret as `AUTUMN_WEBHOOK_SECRET` in your environment
  </Step>

  <Step title="Test the integration">
    Send a test event from the dashboard to verify your endpoint:

    ```bash
    # Check your server logs for the test event
    # Should see: { type: 'test', data: {...} }
    ```
  </Step>
</Steps>

```typescript

    product_id: 'pro_plan',
    status: 'active',
    scenario: 'subscription_started',
    started_at: 1708156800000
  }
}
```

**`customer.product.updated`** - Subscription status changed

```typescript
{
  type: 'customer.product.updated',
```

## Processing Webhook Events

Implement a handler to process different event types:

```typescript
type WebhookEvent = {
  type: string;
  data: any;
  id: string;
  timestamp: number;
};

async function handleWebhookEvent(event: WebhookEvent) {
  console.log(`Processing webhook: ${event.type}`);

  switch (event.type) {
    case 'customer.product.created':
      await handleProductCreated(event.data);
      break;

    case 'customer.product.updated':
      await handleProductUpdated(event.data);
      break;

    case 'customer.product.deleted':
      await handleProductDeleted(event.data);
      break;

    case 'invoice.paid':
      await handleInvoicePaid(event.data);
      break;

    case 'invoice.payment_failed':
      await handlePaymentFailed(event.data);
      break;

    case 'customer.threshold_reached':
      await handleThresholdReached(event.data);
      break;

    default:
      console.log(`Unhandled event type: ${event.type}`);
  }
}
```

## Provisioning Access

Enable features when customers subscribe:

```typescript
async function handleProductCreated(data: any) {
  const { customer_id, product_id, status, scenario } = data;

  if (scenario === 'subscription_started' && status === 'active') {
    // Get product features from your database
    const product = await db.products.findOne({ id: product_id });

    // Enable features for customer
    await db.users.updateOne(
      { autumnCustomerId: customer_id },
      {
        $set: {
          plan: product_id,
          features: product.features,
          subscriptionActive: true
        }
      }
    );

    // Send welcome email
    const user = await db.users.findOne({ autumnCustomerId: customer_id });
    await sendEmail({
      to: user.email,
      subject: `Welcome to ${product.name}!`,
      template: 'subscription_started',
      data: { product, user }
    });

    console.log(`Provisioned access for ${customer_id} to ${product_id}`);
  }
}
```

## Revoking Access

Remove features when subscriptions end:

```typescript
async function handleProductDeleted(data: any) {
  const { customer_id, product_id, status, canceled_at, reason } = data;

  if (status === 'canceled') {
    // Revoke feature access
    await db.users.updateOne(
      { autumnCustomerId: customer_id },
      {
        $set: {
          plan: 'free',
          features: [],
          subscriptionActive: false,
          canceledAt: canceled_at
        }
      }
    );

    // Send cancellation email
    const user = await db.users.findOne({ autumnCustomerId: customer_id });
    await sendEmail({
      to: user.email,
      subject: 'Subscription Canceled',
      template: 'subscription_canceled',
      data: { reason, canceledAt: new Date(canceled_at) }
    });

    console.log(`Revoked access for ${customer_id} from ${product_id}`);
  }
}
```

## Handling Failed Payments

Notify customers and set grace periods:

```typescript
async function handlePaymentFailed(data: any) {
  const { customer_id, invoice_id, amount, error, next_retry } = data;

  // Get customer info
  const user = await db.users.findOne({ autumnCustomerId: customer_id });

  // Send notification
  await sendEmail({
    to: user.email,
    subject: 'Payment Failed - Action Required',
    template: 'payment_failed',
    data: {
      amount: (amount / 100).toFixed(2),
      error,
      retryDate: new Date(next_retry),
      updateUrl: `https://yourapp.com/billing`
    }
  });

  // Set grace period (don't revoke immediately)
  await db.users.updateOne(
    { autumnCustomerId: customer_id },
    {
      $set: {
        paymentStatus: 'past_due',
        gracePeriodEnd: new Date(Date.now() + 3 * 24 * 60 * 60 * 1000) // 3 days
      }
    }
  );

  console.log(`Payment failed for ${customer_id}, grace period set`);
}
```

## Usage Threshold Alerts

Notify customers when approaching limits:

```typescript
async function handleThresholdReached(data: any) {
  const { customer_id, feature, threshold, current_usage, limit } = data;

  const user = await db.users.findOne({ autumnCustomerId: customer_id });
  const remaining = limit - current_usage;

  await sendEmail({
    to: user.email,
    subject: `${threshold}% of ${feature.name} limit reached`,
    template: 'usage_threshold',
    data: {
      feature: feature.name,
      threshold,
      used: current_usage,
      limit,
      remaining,
      percentUsed: threshold,
      upgradeUrl: `https://yourapp.com/upgrade`
    }
  });

  console.log(`Threshold alert sent for ${customer_id} - ${feature.name}`);
}
```

## Webhook Verification

Always verify signatures to prevent spoofing:

```typescript
import { Webhook } from 'svix';

function verifyWebhook(req: Request): WebhookEvent {
  const rawBody = JSON.stringify(req.body);
  const wh = new Webhook(process.env.AUTUMN_WEBHOOK_SECRET!);
  
  try {
    const event = wh.verify(rawBody, {
      'svix-id': req.headers['svix-id'] as string,
      'svix-timestamp': req.headers['svix-timestamp'] as string,
      'svix-signature': req.headers['svix-signature'] as string
    });
    
    return event as WebhookEvent;
  } catch (err) {
    throw new Error('Invalid webhook signature');
  }
}
```

<Warning>
Never process webhooks without verifying signatures. Attackers could send fake events to manipulate your system.
</Warning>

## Idempotency

Webhooks may be delivered multiple times. Make handlers idempotent:

```typescript
async function handleWebhookEvent(event: WebhookEvent) {
  // Check if already processed
  const existing = await db.webhookEvents.findOne({
    eventId: event.id
  });

  if (existing) {
    console.log(`Event ${event.id} already processed`);
    return;
  }

  // Process event
  await processEvent(event);

  // Mark as processed
  await db.webhookEvents.insertOne({
    eventId: event.id,
    type: event.type,
    processedAt: new Date(),
    data: event.data
  });
}
```

## Async Processing

Respond quickly and process asynchronously:

```typescript
import { Queue } from 'bullmq';

const webhookQueue = new Queue('webhooks', {
  connection: redis
});

app.post('/webhooks/autumn', async (req: Request, res: Response) => {
  try {
    const event = verifyWebhook(req);

    // Add to queue for async processing
    await webhookQueue.add('process-webhook', event);

    // Respond immediately
    return res.status(200).json({ received: true });
  } catch (err) {
    console.error('Webhook error:', err);
    return res.status(400).json({ error: 'Invalid webhook' });
  }
});

// Process in worker
const worker = new Worker('webhooks', async (job) => {
  await handleWebhookEvent(job.data);
}, { connection: redis });
```

<Tip>
Respond with 200 OK within 3 seconds to acknowledge receipt, then process events asynchronously to avoid timeouts.
</Tip>

## Monitoring Webhooks

Track webhook processing:

```typescript
const webhookMetrics = {
  processed: 0,
  failed: 0,
  types: new Map<string, number>()
};

async function handleWebhookEvent(event: WebhookEvent) {
  const startTime = Date.now();

  try {
    await processEvent(event);

    webhookMetrics.processed++;
    webhookMetrics.types.set(
      event.type,
      (webhookMetrics.types.get(event.type) || 0) + 1
    );

    const duration = Date.now() - startTime;
    console.log(`Processed ${event.type} in ${duration}ms`);
  } catch (error) {
    webhookMetrics.failed++;
    console.error(`Failed to process ${event.type}:`, error);
    throw error; // Re-throw to trigger retry
  }
}
```
