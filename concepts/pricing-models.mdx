## Overview

Autumn supports a wide range of pricing models to match your business needs. You can implement traditional subscription pricing, usage-based billing, hybrid models, or any combination that works for your product.

This guide explores common pricing patterns and how to configure them using Autumn's products, features, and plan items.

## Subscription Pricing

Fixed recurring charges at regular intervals.

### Simple Monthly Subscription

The most common SaaS pricing model:

```json Example: $29/month
{
  "id": "pro",
  "name": "Pro Plan",
  "price": {
    "amount": 2900,
    "interval": "month"
  },
  "items": [
    {
      "feature_id": "api-calls",
      "included": 10000,
      "unlimited": false,
      "reset": { "interval": "month" }
    }
  ]
}
```

**Characteristics:**
- Fixed monthly charge
- Predictable revenue
- Included allowances
- Resets monthly

### Annual Subscription with Discount

Encourage annual commitments with discounted pricing:

```json Example: $290/year (17% discount)
{
  "id": "pro-annual",
  "name": "Pro Plan (Annual)",
  "price": {
    "amount": 29000,
    "interval": "year"
  },
  "items": [
    {
      "feature_id": "api-calls",
      "included": 120000,
      "unlimited": false,
      "reset": { "interval": "year" }
    }
  ]
}
```

**Benefits:**
- Better cash flow (paid upfront)
- Lower churn (annual commitment)
- Higher customer lifetime value

### Multiple Intervals

Offer flexibility with various billing intervals:

```json Example: Quarterly Billing
{
  "id": "pro-quarterly",
  "name": "Pro Plan (Quarterly)",
  "price": {
    "amount": 8400,
    "interval": "quarter"
  }
}
```

Supported intervals:
- `week` - Weekly
- `month` - Monthly
- `quarter` - Every 3 months
- `semi_annual` - Every 6 months
- `year` - Annually

## Usage-Based Pricing

Charge customers based on actual consumption.

### Pay-as-You-Go

No base fee, pure usage pricing:

```json Example: $0.10 per 1,000 API calls
{
  "id": "pay-as-you-go",
  "name": "Pay as You Go",
  "price": null,
  "items": [
    {
      "feature_id": "api-calls",
      "included": 0,
      "unlimited": false,
      "price": {
        "amount": 10,
        "billing_method": "usage_based",
        "billing_units": 1000,
        "interval": "month"
      }
    }
  ]
}
```

**Characteristics:**
- No upfront cost
- Billed monthly in arrears
- Scales with usage
- Variable monthly cost

### Prepaid Credits

Customers purchase capacity upfront:

```json Example: $100 for 100,000 credits
{
  "id": "credits-bundle",
  "name": "100K Credits",
  "price": {
    "amount": 10000,
    "interval": "one_off"
  },
  "items": [
    {
      "feature_id": "credits",
      "included": 100000,
      "unlimited": false,
      "reset": null
    }
  ]
}
```

**Benefits:**
- Immediate payment
- No surprise bills
- Customer controls spending
- Works like gift cards

### Tiered Usage Pricing

Volume discounts for higher usage:

```json Example: Decreasing per-unit cost
{
  "feature_id": "api-calls",
  "included": 0,
  "unlimited": false,
  "price": {
    "tiers": [
      {
        "to": 10000,
        "amount": 10
      },
      {
        "to": 100000,
        "amount": 8
      },
      {
        "to": "infinite",
        "amount": 5
      }
    ],
    "billing_method": "usage_based",
    "billing_units": 1000,
    "interval": "month"
  }
}
```

**Pricing breakdown:**
- 0-10k calls: $0.01 each ($100 max)
- 10k-100k calls: $0.008 each ($720 max)
- 100k+ calls: $0.005 each (no limit)

<Info>
A customer using 150,000 API calls pays:<br/>
$100 (first 10k) + $720 (next 90k) + $250 (final 50k) = **$1,070**
</Info>

## Hybrid Pricing

Combine subscription and usage-based components.

### Base + Overage

Fixed base fee with usage charges for overages:

```json Example: $19/month + $0.005 per extra call
{
  "id": "hybrid",
  "name": "Hybrid Plan",
  "price": {
    "amount": 1900,
    "interval": "month"
  },
  "items": [
    {
      "feature_id": "api-calls",
      "included": 5000,
      "unlimited": false,
      "reset": { "interval": "month" },
      "price": {
        "amount": 5,
        "billing_method": "usage_based",
        "billing_units": 1000,
        "interval": "month"
      }
    }
  ]
}
```

**How it works:**
- Month 1: Used 3,000 calls → Pay $19 (no overage)
- Month 2: Used 8,000 calls → Pay $19 + $15 overage = $34
- Month 3: Used 15,000 calls → Pay $19 + $50 overage = $69

### Multiple Feature Types

Combine fixed features with metered features:

```json Example: Mixed Entitlements
{
  "id": "professional",
  "name": "Professional",
  "price": {
    "amount": 4900,
    "interval": "month"
  },
  "items": [
    {
      "feature_id": "team-seats",
      "included": 10,
      "unlimited": false,
      "reset": { "interval": "month" }
    },
    {
      "feature_id": "storage-gb",
      "included": 100,
      "unlimited": false,
      "reset": { "interval": "month" },
      "price": {
        "amount": 50,
        "billing_method": "usage_based",
        "billing_units": 10,
        "interval": "month"
      }
    },
    {
      "feature_id": "advanced-analytics",
      "unlimited": true
    }
  ]
}
```

**What's included:**
- 10 seats (fixed)
- 100 GB storage (fixed) + $0.50/GB overage
- Advanced analytics (unlimited access)

## Per-Seat Pricing

Charge based on number of users.

### Simple Per-Seat

```json Example: $15 per user/month
{
  "id": "team",
  "name": "Team Plan",
  "price": {
    "amount": 1500,
    "interval": "month",
    "display": {
      "primary_text": "$15",
      "secondary_text": "per user/month"
    }
  }
}
```

**Usage:**

```typescript Subscribe with Quantity
await autumn.attach({
  customer_id: "org_123",
  product_id: "team",
  quantity: 5  // 5 users × $15 = $75/month
});
```

### Graduated Per-Seat Pricing

Volume discounts for larger teams:

```json Example: Decreasing per-seat cost
{
  "items": [
    {
      "feature_id": "seats",
      "included": 0,
      "price": {
        "tiers": [
          {
            "to": 10,
            "amount": 1500  // $15/user for 1-10
          },
          {
            "to": 50,
            "amount": 1200  // $12/user for 11-50
          },
          {
            "to": "infinite",
            "amount": 1000  // $10/user for 51+
          }
        ],
        "billing_method": "usage_based",
        "billing_units": 1,
        "interval": "month"
      }
    }
  ]
}
```

## Free Trial Pricing

Offer trial periods before charging.

### Trial with Credit Card

```json Example: 14-Day Trial, Card Required
{
  "id": "pro",
  "name": "Pro Plan",
  "price": {
    "amount": 2900,
    "interval": "month"
  },
  "free_trial": {
    "duration_length": 14,
    "duration_type": "day",
    "card_required": true
  }
}
```

**What happens:**
- Day 0: Customer enters card, trial starts
- Days 1-13: Full access, no charge
- Day 14: Trial ends, first charge of $29

### Trial without Credit Card

```json Example: 7-Day Trial, No Card
{
  "free_trial": {
    "duration_length": 7,
    "duration_type": "day",
    "card_required": false
  }
}
```

**What happens:**
- Day 0: Customer signs up, trial starts
- Days 1-6: Full access, no card required
- Day 7: Trial expires, must add card to continue

```json Example: Universal Credits
{

    "amount": 10000,
    "interval": "one_off"
  },
  "items": [
    {
      "feature_id": "credits",
      "included": 1000,
      "unlimited": false
    }
  ]

```

With credit feature defined as:

```json Credit Schema
{
  "id": "credits",
  "type": "credit_system",
  "credit_schema": [

      "metered_feature_id": "api-calls",
      "credit_cost": 1
```

**How customers spend:**
- 1,000 API calls (1 credit each) = 1,000 credits
- OR 100 AI generations (10 credits each) = 1,000 credits
- OR 20 video transcodes (50 credits each) = 1,000 credits
- OR any combination

## Choosing the Right Model

### Use Subscription When:
- Predictable revenue is critical
- Costs are mostly fixed (not usage-dependent)
- Customers want budget certainty
- Simple pricing is important

### Use Usage-Based When:
- Costs scale directly with usage
- Customer usage varies widely
- Want to attract price-conscious customers
- Value is clearly tied to consumption

### Use Hybrid When:
- Need predictable base revenue
- Usage varies but want to capture overage
- Customers want included allowance
- Balancing simplicity and flexibility

### Use Tiered When:
- Clear customer segments exist
- Feature bundling makes sense
- Upselling is important strategy
- Different value propositions per tier

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Can I combine subscription and usage pricing for the same feature?">
    Yes! Use hybrid pricing:
    ```json
    {
      "price": { "amount": 2900, "interval": "month" },
      "items": [{
        "feature_id": "api-calls",
        "included": 10000,
        "price": {
          "amount": 10,
          "billing_method": "usage_based",
          "billing_units": 1000
        }
      }]
    }
    ```
    Customers pay $29/month + $10 per 1,000 API calls over 10k.
  </Accordion>

  <Accordion title="How do I implement volume discounts?">
    Use tiered pricing with decreasing per-unit costs:
    ```json
    {
      "tiers": [
        { "to": 10000, "amount": 100 },
        { "to": 100000, "amount": 80 },
        { "to": "infinite", "amount": 50 }
      ]
    }
    ```
  </Accordion>

  <Accordion title="Can customers switch between pricing models?">
    Yes, by attaching to a different product:
    ```typescript
    // Switch from subscription to usage-based
    await autumn.attach({
      customer_id: "user_123",
      product_id: "pay-as-you-go"
    });
    ```
    
    Autumn handles proration automatically.
  </Accordion>

  <Accordion title="What's the difference between prepaid and usage_based billing?">
    **Prepaid**: Customer buys capacity upfront, balance decrements
    ```json
    { "billing_method": "prepaid" }
    ```
    
    **Usage-based**: Track usage, bill at end of period
    ```json
    { "billing_method": "usage_based" }
    ```
    
    Prepaid = pay first, consume later<br/>
    Usage-based = consume first, pay later
  </Accordion>

  <Accordion title="How do I grandfather old pricing for existing customers?">
    Create new product versions:
    1. Update product with new pricing
    2. New customers get new pricing automatically
    3. Existing customers keep old pricing until they upgrade
    
    Or create separate product variants:
    ```json
    { "id": "pro-legacy", "archived": true }
    { "id": "pro-v2", "archived": false }
    ```
  </Accordion>
</AccordionGroup>
