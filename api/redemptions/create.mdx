---
title: "Redeem Referral Code"
api: "POST /redemptions"
description: "Redeem a referral code for a customer"
---

Redeem a referral code on behalf of a customer. When a customer uses a referral code, they may receive rewards based on your referral program configuration, and the referrer may also receive rewards.

## Request

<ParamField body="code" type="string" required>
  The referral code to redeem (e.g., "REF123ABC").
</ParamField>

<ParamField body="customer_id" type="string" required>
  The unique identifier of the customer who is redeeming the code.
</ParamField>

## Response

<ResponseField name="id" type="string">
  The unique identifier for this redemption event.
</ResponseField>

<ResponseField name="customer_id" type="string">
  Your unique identifier for the customer who redeemed the code.
</ResponseField>

<ResponseField name="reward_id" type="string">
  The ID of the reward that will be granted to this customer.
</ResponseField>

<ResponseField name="referrer" type="object">
  Information about the customer who created the referral code.

  <Expandable title="Referrer Object">
    <ResponseField name="id" type="string">
      The referrer's customer ID.
    </ResponseField>

    <ResponseField name="name" type="string | null">
      The referrer's name.
    </ResponseField>

    <ResponseField name="email" type="string | null">
      The referrer's email address.
    </ResponseField>

    <ResponseField name="created_at" type="number">
      Unix timestamp when the referrer was created.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="redeemer" type="object">
  Information about the customer who redeemed the code.

  <Expandable title="Redeemer Object">
    <ResponseField name="id" type="string">
      The redeemer's customer ID.
    </ResponseField>

    <ResponseField name="name" type="string | null">
      The redeemer's name.
    </ResponseField>

    <ResponseField name="email" type="string | null">
      The redeemer's email address.
    </ResponseField>

    <ResponseField name="created_at" type="number">
      Unix timestamp when the redeemer was created.
    </ResponseField>
  </Expandable>
</ResponseField>

## Important Notes

- **One redemption per program**: A customer can only redeem one code per referral program. Attempting to redeem a second code from the same program will result in an error.
- **Max redemptions**: Referral codes may have a maximum number of redemptions configured. Once reached, the code cannot be redeemed again.
- **Self-redemption prevention**: Customers cannot redeem their own referral codes. The system checks both customer ID and device fingerprint to prevent abuse.
- **Reward timing**: Depending on your referral program configuration, rewards may be granted immediately or triggered by specific events (e.g., first purchase).

## Error Handling

<ResponseField name="400" type="error">
  **Bad Request** - Invalid parameters. Common causes:
  - Missing code or customer_id
  - Invalid referral code format
  - Customer already redeemed a code in this program
  - Customer attempting to redeem their own code
  - Referral code has reached maximum redemptions
</ResponseField>

<ResponseField name="401" type="error">
  **Unauthorized** - Invalid or missing API key.
</ResponseField>

<ResponseField name="404" type="error">
  **Not Found** - The referral code or customer does not exist.
</ResponseField>

<ResponseField name="500" type="error">
  **Internal Server Error** - An unexpected error occurred on the server.
</ResponseField>

## Error Codes

Specific error codes you may encounter:

- `referral_code_max_redemptions_reached` - The referral code has been used the maximum number of times
- `customer_already_redeemed_referral_code` - This customer has already redeemed a code in this referral program
- `customer_cannot_redeem_own_code` - Customer is attempting to use their own referral code
- `customer_not_found` - The specified customer does not exist
- `referral_code_not_found` - The referral code does not exist or is invalid
