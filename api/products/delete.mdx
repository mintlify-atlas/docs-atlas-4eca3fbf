---
title: "Delete Product"
api: "DELETE /products/{product_id}"
---

Deletes a product. Products can only be deleted if they have no active or expired customers.

## Path Parameters

<ParamField path="product_id" type="string" required>
  The ID of the product to delete.
</ParamField>

## Query Parameters

<ParamField query="all_versions" type="boolean" default={false}>
  If `true`, deletes all versions of the product. If `false`, only deletes the latest version.
  
  **Note**: Deletion will fail if any version has customers, regardless of this setting.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Returns `true` if the deletion was successful.
</ResponseField>

<RequestExample>
```bash cURL
curl --request DELETE \
  --url https://api.autumn.ai/products/old-plan \
  --header 'Authorization: Bearer <token>'
```

```typescript TypeScript
import { Autumn } from '@autumnai/node-sdk';

const autumn = new Autumn({
  apiKey: process.env.AUTUMN_API_KEY,
});

// Delete latest version only
await autumn.products.delete('old-plan');

// Delete all versions
await autumn.products.delete('old-plan', {
  all_versions: true,
});
```

```python Python
from autumn import Autumn

autumn = Autumn(api_key="your_api_key")

# Delete latest version only
autumn.products.delete("old-plan")

# Delete all versions
autumn.products.delete("old-plan", all_versions=True)
```
</RequestExample>

## Deletion Rules

### When Can You Delete?

A product can be deleted when:
- It has **no active customers**
- It has **no expired customers** (customers who previously had the product)
- No subscriptions reference this product

### When Can't You Delete?

A product **cannot** be deleted when:
- Any customers currently have the product attached
- Any customers previously had the product (even if expired)
- Any subscriptions reference this product

### Versioned Products

If a product has multiple versions:

**Delete Latest Version** (`all_versions=false`, default):
- Only deletes the most recent version
- Older versions remain intact
- Fails if the latest version has any customers

**Delete All Versions** (`all_versions=true`):
- Attempts to delete all versions of the product
- Fails if **any** version has any customers
- Removes all product data for this product ID

## Before Deleting

### Check Customer Count

Before attempting deletion, you can check if a product has customers using the deletion info endpoint:

```bash
curl --request GET \
  --url https://api.autumn.ai/products/old-plan/deletion_info \
  --header 'Authorization: Bearer <token>'
```

This returns:
```json
{
  "active_customers": 0,
  "expired_customers": 5,
  "total_customers": 5,
  "can_delete": false
}
```

### Check Has Customers

Alternatively, use the has_customers endpoint:

```bash
curl --request GET \
  --url https://api.autumn.ai/products/old-plan/has_customers \
  --header 'Authorization: Bearer <token>'
```

Returns:
```json
{
  "has_customers": true,
  "count": 5
}
```

## Alternative to Deletion: Archiving

If you can't delete a product because it has customers, consider **archiving** instead:

```bash
curl --request POST \
  --url https://api.autumn.ai/products/old-plan \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "archived": true
}'
```

Archiving a product:
- Hides it from your dashboard
- Prevents new customers from purchasing it
- Keeps existing customers on the product
- Maintains all product data and history
- Can be reversed by setting `archived: false`

## What Gets Deleted

When a product is successfully deleted, the following are removed:
- The product record
- All associated prices
- All associated entitlements
- Free trial configuration
- Product versioning data (if `all_versions=true`)

**Not deleted**:
- Features referenced by the product (features exist independently)
- Historical usage data
- Invoice records

## Common Scenarios

### Delete Test Product

You created a product for testing and it has no customers:

```typescript
await autumn.products.delete('test-product');
// ✅ Success - product deleted
```

### Delete Product With Customers

You try to delete a product that has customers:

```typescript
await autumn.products.delete('popular-plan');
// ❌ Error: Product has customers
```

Solution: Archive instead

```typescript
await autumn.products.update('popular-plan', {
  archived: true,
});
// ✅ Success - product archived
```

### Delete Old Version

You want to clean up old versions:

```typescript
// This will fail if version 1 has any customers
await autumn.products.delete('pro-plan?version=1');
```

**Note**: You typically cannot delete old versions because customers are on them.

### Delete All Versions

You want to completely remove a product:

```typescript
await autumn.products.delete('deprecated-plan', {
  all_versions: true,
});
// Only works if no version has any customers
```

## Notes

- Deletion is permanent and cannot be undone
- Always check customer count before attempting deletion
- Consider archiving instead of deleting for products with history
- Deleting a default product will not automatically assign a new default
- Features used by the product will not be deleted
- Deletion fails immediately if customers exist, no partial deletion occurs
