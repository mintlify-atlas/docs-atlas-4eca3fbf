---
title: "List Products"
api: "GET /products"
---

Retrieves a list of all products in your environment. You can optionally filter by customer to see customer-specific information.

## Query Parameters

<ParamField query="customer_id" type="string">
  Optional customer ID. When provided, the response includes customer-specific information like trial eligibility and upgrade/downgrade scenarios.
</ParamField>

<ParamField query="entity_id" type="string">
  Optional entity ID to filter products by a specific entity context. Used in conjunction with `customer_id`.
</ParamField>

<ParamField query="include_archived" type="boolean" default={false}>
  If `true`, includes archived products in the response. By default, only active products are returned.
</ParamField>

## Response

<ResponseField name="list" type="array">
  Array of product objects. Each product contains the same fields as [Retrieve Product](/api/products/retrieve#response).
</ResponseField>

<RequestExample>
```bash cURL
curl --request GET \
  --url https://api.autumn.ai/products \
  --header 'Authorization: Bearer <token>'
```

```bash With Customer Context
curl --request GET \
  --url 'https://api.autumn.ai/products?customer_id=cus_123' \
  --header 'Authorization: Bearer <token>'
```

```typescript TypeScript
import { Autumn } from '@autumnai/node-sdk';

const autumn = new Autumn({
  apiKey: process.env.AUTUMN_API_KEY,
});

// List all products
const products = await autumn.products.list();

console.log(`Found ${products.list.length} products`);

// List with customer context
const withCustomer = await autumn.products.list({
  customer_id: 'cus_123',
});

// Check upgrade opportunities
for (const product of withCustomer.list) {
  if (product.customer_eligibility?.scenario === 'upgrade') {
    console.log(`${product.name} is an upgrade option`);
  }
}

// Include archived products
const allProducts = await autumn.products.list({
  include_archived: true,
});
```

```python Python
from autumn import Autumn

autumn = Autumn(api_key="your_api_key")

# List all products
products = autumn.products.list()

print(f"Found {len(products.list)} products")

# List with customer context
with_customer = autumn.products.list(customer_id="cus_123")

# Check upgrade opportunities
for product in with_customer.list:
    if product.get("customer_eligibility", {}).get("scenario") == "upgrade":
        print(f"{product['name']} is an upgrade option")

# Include archived products
all_products = autumn.products.list(include_archived=True)
```

## Filtering and Sorting

### By Product Type

Filter products by type in your application code:

```typescript
const products = await autumn.products.list();

// Get only subscription products (products with base price)
const subscriptions = products.list.filter(p => p.price !== null);

// Get only add-ons
const addons = products.list.filter(p => p.add_on === true);

// Get only free products
const freePlans = products.list.filter(p => p.price === null);

// Get default product
const defaultProduct = products.list.find(p => p.auto_enable === true);
```

### By Product Group

```typescript
const products = await autumn.products.list();

// Get products in a specific group
const mainPlans = products.list.filter(p => p.group === 'main');

// Group products by group
const grouped = products.list.reduce((acc, product) => {
  const group = product.group || 'ungrouped';
  if (!acc[group]) acc[group] = [];
  acc[group].push(product);
  return acc;
}, {});
```

### Sort Products

```typescript
const products = await autumn.products.list();

// Sort by price (ascending)
const byPrice = [...products.list].sort((a, b) => {
  const priceA = a.price?.amount || 0;
  const priceB = b.price?.amount || 0;
  return priceA - priceB;
});

// Sort by name
const byName = [...products.list].sort((a, b) => 
  a.name.localeCompare(b.name)
);

// Sort by creation date (newest first)
const byDate = [...products.list].sort((a, b) => 
  b.created_at - a.created_at
);
```

## Customer Context

When you provide a `customer_id`, each product includes a `customer_eligibility` object:

### Scenario Types

- `current`: Customer currently has this product
- `new`: Customer doesn't have any product in this group
- `upgrade`: Switching to this product would be an upgrade
- `downgrade`: Switching to this product would be a downgrade
- `cross_group`: Product is in a different group
- `add_on`: Product is an add-on (can be purchased alongside current product)

### Trial Availability

```typescript
const products = await autumn.products.list({
  customer_id: 'cus_123',
});

for (const product of products.list) {
  const { trial_available, scenario } = product.customer_eligibility;
  
  if (trial_available) {
    console.log(`${product.name} offers a free trial`);
  }
  
  if (scenario === 'upgrade') {
    console.log(`${product.name} is an upgrade from current plan`);
  }
}
```

## Common Use Cases

### Build Pricing Page

```typescript
const products = await autumn.products.list();

// Filter and sort for pricing page
const pricingTiers = products.list
  .filter(p => p.group === 'main' && !p.archived && !p.add_on)
  .sort((a, b) => (a.price?.amount || 0) - (b.price?.amount || 0));

// Display each tier
for (const product of pricingTiers) {
  console.log(`${product.name}: $${product.price?.amount || 0}/month`);
  console.log('Features:');
  for (const item of product.items) {
    if (item.unlimited) {
      console.log(`  - Unlimited ${item.feature_id}`);
    } else if (item.included) {
      console.log(`  - ${item.included} ${item.feature_id}`);
    }
  }
}
```

### Show Upgrade Options

```typescript
const products = await autumn.products.list({
  customer_id: 'cus_123',
});

const upgrades = products.list.filter(
  p => p.customer_eligibility?.scenario === 'upgrade'
);

if (upgrades.length > 0) {
  console.log('Available upgrades:');
  for (const product of upgrades) {
    console.log(`- ${product.name}: $${product.price?.amount}/month`);
  }
}
```

### List Add-ons

```typescript
const products = await autumn.products.list();

const addons = products.list.filter(p => p.add_on && !p.archived);

console.log('Available add-ons:');
for (const addon of addons) {
  console.log(`${addon.name}: $${addon.price?.amount}/${addon.price?.interval}`);
}
```

## Notes

- Returns only the latest version of each product (older versions are not included)
- Products are not sorted by default, sort in your application as needed
- Use `include_archived: true` to see all products including archived ones
- Customer context adds `customer_eligibility` to help build upgrade/downgrade flows
- Add-ons appear in the list regardless of product groups
- Empty array is returned if no products exist
