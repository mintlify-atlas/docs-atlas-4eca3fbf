---
title: 'List Products'
api: 'GET /plans'
---

Retrieve a list of all products (plans) for your organization.

## Query Parameters

<ParamField query="customer_id" type="string" optional>
  Filter products by customer eligibility. When provided, the response includes customer-specific information like trial availability and attach scenarios.
</ParamField>

## Response

Returns an object with a `list` property containing an array of product objects.

<ResponseField name="list" type="array">
  Array of product objects
  
  <Expandable title="Product Object">
    <ResponseField name="id" type="string">
      Unique identifier for the product
    </ResponseField>
    
    <ResponseField name="name" type="string">
      Display name of the product
    </ResponseField>
    
    <ResponseField name="description" type="string | null">
      Optional description of the product
    </ResponseField>
    
    <ResponseField name="group" type="string | null">
      Product group for managing upgrades/downgrades
    </ResponseField>
    
    <ResponseField name="version" type="number">
      Version number of the product
    </ResponseField>
    
    <ResponseField name="add_on" type="boolean">
      Whether this is an add-on product
    </ResponseField>
    
    <ResponseField name="default" type="boolean">
      Whether this is the default product for new customers
    </ResponseField>
    
    <ResponseField name="price" type="object | null">
      Base subscription price
      
      <Expandable title="Price Object">
        <ResponseField name="amount" type="number">
          Price amount in cents
        </ResponseField>
        
        <ResponseField name="interval" type="string">
          Billing interval: `month`, `year`, `week`, or `day`
        </ResponseField>
        
        <ResponseField name="interval_count" type="number" optional>
          Number of intervals between billings (e.g., 3 for quarterly)
        </ResponseField>
        
        <ResponseField name="display" type="object" optional>
          Display configuration for pricing UI
        </ResponseField>
      </Expandable>
    </ResponseField>
    
    <ResponseField name="features" type="array">
      Array of features included in this product
      
      <Expandable title="Feature Object">
        <ResponseField name="feature_id" type="string">
          ID of the feature
        </ResponseField>
        
        <ResponseField name="feature" type="object" optional>
          Full feature object with name, type, etc.
        </ResponseField>
        
        <ResponseField name="granted_balance" type="number">
          Amount of usage granted for this feature
        </ResponseField>
        
        <ResponseField name="unlimited" type="boolean">
          Whether usage is unlimited
        </ResponseField>
        
        <ResponseField name="reset" type="object | null">
          Reset interval configuration for metered features
        </ResponseField>
        
        <ResponseField name="price" type="object | null">
          Pricing for additional usage beyond included amount
        </ResponseField>
      </Expandable>
    </ResponseField>
    
    <ResponseField name="free_trial" type="object | null" optional>
      Free trial configuration
      
      <Expandable title="Free Trial Object">
        <ResponseField name="duration_length" type="number">
          Length of the trial period
        </ResponseField>
        
        <ResponseField name="duration_type" type="string">
          Unit of duration: `day`, `week`, `month`, or `year`
        </ResponseField>
        
        <ResponseField name="card_required" type="boolean">
          Whether a payment method is required to start the trial
        </ResponseField>
      </Expandable>
    </ResponseField>
    
    <ResponseField name="created_at" type="number">
      Unix timestamp of creation
    </ResponseField>
    
    <ResponseField name="env" type="string">
      Environment: `production` or `development`
    </ResponseField>
    
    <ResponseField name="archived" type="boolean">
      Whether the product is archived
    </ResponseField>
    
    <ResponseField name="base_variant_id" type="string | null">
      ID of the base product variant
    </ResponseField>
    
    <ResponseField name="customer_eligibility" type="object" optional>
      Customer-specific eligibility information (only when `customer_id` is provided)
      
      <Expandable title="Customer Eligibility Object">
        <ResponseField name="trial_available" type="boolean" optional>
          Whether the customer is eligible for a free trial
        </ResponseField>
        
        <ResponseField name="scenario" type="string">
          Attach scenario: `new`, `upgrade`, `downgrade`, `addon`, etc.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

<ResponseField name="error" type="object">
  <Expandable title="Error Object">
    <ResponseField name="message" type="string">
      Human-readable error message
    </ResponseField>
    
    <ResponseField name="code" type="string">
      Machine-readable error code
    </ResponseField>
  </Expandable>
</ResponseField>

### Common Errors

- **401 Unauthorized**: Invalid or missing API key
- **403 Forbidden**: API key doesn't have access to this resource
- **500 Internal Server Error**: Something went wrong on Autumn's end

## Notes

- Products are returned in the order they were created
- Archived products are excluded by default
- When `customer_id` is provided, the response includes eligibility information for each product
- See [Products & Plans](/concepts/products-and-plans) for more information about product structure
