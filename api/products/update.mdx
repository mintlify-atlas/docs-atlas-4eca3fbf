---
title: 'Update Product'
api: 'POST /plans/{plan_id}'
---

Update an existing product (plan). If customers are already attached to this product and you modify features or pricing, a new version will be automatically created.

## Path Parameters

<ParamField path="plan_id" type="string" required>
  The unique identifier of the product to update.
</ParamField>

## Query Parameters

<ParamField query="version" type="number" optional>
  Specific version of the product to update. If not provided, updates the latest version.
</ParamField>

<ParamField query="upsert" type="boolean" optional>
  If `true`, creates the product if it doesn't exist.
</ParamField>

<ParamField query="disable_version" type="boolean" optional>
  If `true`, prevents automatic versioning even when customers exist. Use with caution as this can affect existing customers.
</ParamField>

## Request Body

All fields are optional. Only include fields you want to update.

<ParamField body="id" type="string" optional>
  New product ID. Use with caution as this changes how the product is referenced.
</ParamField>

<ParamField body="name" type="string" optional>
  Updated display name of the product.
</ParamField>

<ParamField body="description" type="string | null" optional>
  Updated description of the product.
</ParamField>

<ParamField body="add_on" type="boolean" optional>
  Whether this is an add-on product.
</ParamField>

<ParamField body="auto_enable" type="boolean" optional>
  Whether to automatically enable this product for new customers.
</ParamField>

<ParamField body="group" type="string" optional>
  Product group name for upgrade/downgrade logic.
</ParamField>

<ParamField body="archived" type="boolean" optional>
  Archive or unarchive the product. Archived products are hidden from the dashboard but remain attached to existing customers.
</ParamField>

<ParamField body="price" type="object" optional>
  Updated base subscription price.
  
  <Expandable title="Price Object">
    <ParamField body="amount" type="number" required>
      Price amount in cents
    </ParamField>
    
    <ParamField body="interval" type="string" required>
      Billing interval: `month`, `year`, `week`, or `day`
    </ParamField>
    
    <ParamField body="interval_count" type="number" optional>
      Number of intervals between billings
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="items" type="array" optional>
  Updated array of product items. Replaces all existing items.
  
  <Warning>Modifying `items` when customers exist triggers automatic versioning unless `disable_version=true`.</Warning>
  
  <Expandable title="Product Item Object">
    <ParamField body="feature_id" type="string" required>
      ID of the feature
    </ParamField>
    
    <ParamField body="granted_balance" type="number" optional>
      Amount of usage granted
    </ParamField>
    
    <ParamField body="unlimited" type="boolean" optional>
      Set to `true` for unlimited usage
    </ParamField>
    
    <ParamField body="reset" type="object" optional>
      Reset configuration for metered features
    </ParamField>
    
    <ParamField body="price" type="object" optional>
      Pricing for additional usage
    </ParamField>
    
    <ParamField body="rollover" type="object" optional>
      Rollover configuration
    </ParamField>
    
    <ParamField body="proration" type="object" optional>
      Proration behavior
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="free_trial" type="object | null" optional>
  Updated free trial configuration. Set to `null` to remove the trial.
  
  <Warning>Modifying `free_trial` when customers exist triggers automatic versioning unless `disable_version=true`.</Warning>
  
  <Expandable title="Free Trial Object">
    <ParamField body="duration_length" type="number" required>
      Length of the trial period
    </ParamField>
    
    <ParamField body="duration_type" type="string" default="month">
      Unit of duration: `day`, `week`, `month`, or `year`
    </ParamField>
    
    <ParamField body="card_required" type="boolean" default={true}>
      Whether a payment method is required
    </ParamField>
  </Expandable>
</ParamField>

## Response

Returns the updated product object if successful.

## Error Responses

### Common Errors

- **400 Bad Request**: Invalid request body or parameters
  - Cannot auto-save when customers exist and `disable_version=true`
  - Invalid pricing configuration
  - Referenced feature doesn't exist
- **404 Not Found**: No product exists with the provided ID
- **401 Unauthorized**: Invalid or missing API key
- **403 Forbidden**: API key doesn't have permission to update products
- **500 Internal Server Error**: Something went wrong on Autumn's end

## Versioning Behavior

When you update a product that has active customers:

1. **Metadata changes only** (name, description, group, archived): Updates in place, no new version
2. **Feature/pricing changes** (items, free_trial): Creates a new version automatically
   - New customers get the new version
   - Existing customers remain on their current version
   - The `version` field increments
   - The `base_variant_id` points to the original product ID

### Preventing Auto-Versioning

Use `disable_version=true` to update the product in place even when customers exist. This will:
- Update the product for ALL customers, including existing ones
- Not create a new version
- Should be used carefully as it affects existing subscriptions

<Warning>
Using `disable_version=true` when customers exist will throw an error for safety. Only use this when you understand the implications.
</Warning>

## Notes

- Product updates are reflected immediately
- Updating `items` replaces all existing product items
- See [Products & Plans](/concepts/products-and-plans) for more about versioning
- For migration between versions, see the Migration API
