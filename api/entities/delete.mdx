## Overview

Delete an entity from a customer. This operation handles cleanup of associated subscriptions, balances, and entitlements. Deleting an entity may free up allowances in metered features and cancel active subscriptions tied to the entity.

<Warning>
  Deleting an entity is permanent and cannot be undone. Make sure you want to proceed before calling this endpoint.
</Warning>

## Endpoint

```
DELETE /customers/{customer_id}/entities/{entity_id}
```

## Path Parameters

<ParamField path="customer_id" type="string" required>
  The unique identifier of the customer who owns the entity
</ParamField>

<ParamField path="entity_id" type="string" required>
  The unique identifier of the entity to delete
</ParamField>

## Response

Returns a success confirmation object.

<ResponseField name="success" type="boolean">
  Indicates whether the deletion was successful
</ResponseField>

## What Happens When You Delete an Entity

When you delete an entity, Autumn automatically:

1. **Adjusts allowances** - If the entity was consuming a metered feature allowance, that allowance is freed up
2. **Updates entitlements** - Removes the entity from customer entitlements and may replace it with available replaceables
3. **Cancels subscriptions** - Any active subscriptions specifically tied to this entity are cancelled
4. **Preserves history** - Usage events and invoices related to the entity are retained for historical records

## Example Request

<CodeGroup>
```bash cURL
curl -X DELETE https://api.autumnhq.com/v1/customers/cus_123/entities/user_001 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```typescript TypeScript
const response = await fetch(
  'https://api.autumnhq.com/v1/customers/cus_123/entities/user_001',
  {
    method: 'DELETE',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);

const data = await response.json();
```

```python Python
import requests

response = requests.delete(
    'https://api.autumnhq.com/v1/customers/cus_123/entities/user_001',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)

data = response.json()
```
</CodeGroup>

## Use Cases

### User Leaves Team

When a user is removed from a team, delete their entity to free up the seat allowance:

```typescript
await fetch(
  'https://api.autumnhq.com/v1/customers/team_abc/entities/user_123',
  {
    method: 'DELETE',
    headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
  }
);
```

### Project Deleted

When a project is deleted from your application, remove the corresponding entity:

```typescript
await fetch(
  'https://api.autumnhq.com/v1/customers/company_xyz/entities/project_456',
  {
    method: 'DELETE',
    headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
  }
);
```

### API Key Revoked

When an API key is revoked, delete its entity to stop tracking its usage:

```typescript
await fetch(
  'https://api.autumnhq.com/v1/customers/account_789/entities/api_key_xyz',
  {
    method: 'DELETE',
    headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
  }
);
```

## Best Practices

<AccordionGroup>
  <Accordion title="Verify before deletion">
    Always retrieve the entity first to confirm you're deleting the correct one:
    
    ```typescript
    // Get entity to verify
    const entity = await fetch(
      'https://api.autumnhq.com/v1/customers/cus_123/entities/user_001',
      { headers: { 'Authorization': 'Bearer YOUR_API_KEY' } }
    ).then(r => r.json());
    
    // Verify it's the right entity
    if (entity.name === 'Expected Name') {
      // Proceed with deletion
      await fetch(
        'https://api.autumnhq.com/v1/customers/cus_123/entities/user_001',
        {
          method: 'DELETE',
          headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
        }
      );
    }
    ```
  </Accordion>
  
  <Accordion title="Handle errors gracefully">
    Entity might already be deleted by another process. Handle 404 errors appropriately:
    
    ```typescript
    try {
      await fetch(
        'https://api.autumnhq.com/v1/customers/cus_123/entities/user_001',
        {
          method: 'DELETE',
          headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
        }
      );
    } catch (error) {
      if (error.code === 'entity_not_found') {
        // Entity already deleted, that's okay
        console.log('Entity already deleted');
      } else {
        // Handle other errors
        throw error;
      }
    }
    ```
  </Accordion>
  
  <Accordion title="Consider webhook notifications">
    If you use webhooks, deleting an entity may trigger events. Make sure your webhook handlers can process entity deletion events appropriately.
  </Accordion>
</AccordionGroup>

## Notes

- Deletion is permanent and cannot be undone
- Historical usage data and invoices are preserved even after entity deletion
- Deleting an entity may free up allowances in metered features for the customer
- Active subscriptions tied to the entity will be cancelled according to your cancellation policies
- The operation processes in the background and handles all necessary cleanup automatically
