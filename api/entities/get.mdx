## Overview

Retrieve detailed information about a specific entity. You can optionally expand related resources such as invoices, subscriptions, and balances.

## Endpoint

```
GET /customers/{customer_id}/entities/{entity_id}
```

## Path Parameters

<ParamField path="customer_id" type="string" required>
  The unique identifier of the customer who owns the entity
</ParamField>

<ParamField path="entity_id" type="string" required>
  The unique identifier of the entity to retrieve
</ParamField>

## Query Parameters

<ParamField query="expand" type="array">
  Comma-separated list of resources to expand in the response. Available values:
  
  - `invoices` - Include invoices for this entity
  - `subscriptions.plan` - Include subscription details with plan information
  - `purchases.plan` - Include purchase details with plan information
  - `balances.feature` - Include balance details with feature information
</ParamField>

<ParamField query="skip_cache" type="boolean" default="false">
  Skip cache and fetch fresh data from the database
</ParamField>

<ParamField query="with_autumn_id" type="boolean" default="false">
  Include internal Autumn ID in the response
</ParamField>

## Response

Returns an entity object.

<ResponseField name="id" type="string">
  The unique identifier of the entity
</ResponseField>

<ResponseField name="name" type="string">
  The name of the entity
</ResponseField>

<ResponseField name="customer_id" type="string">
  The customer ID this entity belongs to
</ResponseField>

<ResponseField name="feature_id" type="string">
  The feature ID this entity belongs to
</ResponseField>

<ResponseField name="created_at" type="number">
  Unix timestamp when the entity was created
</ResponseField>

<ResponseField name="env" type="string">
  The environment (sandbox/live)
</ResponseField>

<ResponseField name="autumn_id" type="string" optional>
  Internal Autumn identifier (only included when `with_autumn_id=true`)
</ResponseField>

<ResponseField name="subscriptions" type="array" optional>
  Plans associated with this entity (when expanded)
  
  <Expandable title="Subscription object">
    <ResponseField name="id" type="string">
      Subscription ID
    </ResponseField>
    
    <ResponseField name="status" type="string">
      Subscription status (active, canceled, etc.)
    </ResponseField>
    
    <ResponseField name="plan" type="object" optional>
      Plan details (when `expand=subscriptions.plan`)
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="scheduled_subscriptions" type="array">
  Scheduled subscriptions for this entity
</ResponseField>

<ResponseField name="balances" type="object" optional>
  Features associated with this entity (when expanded)
  
  <Expandable title="Balance object">
    <ResponseField name="feature_id" type="string">
      Feature ID
    </ResponseField>
    
    <ResponseField name="balance" type="number">
      Current balance
    </ResponseField>
    
    <ResponseField name="feature" type="object" optional>
      Feature details (when `expand=balances.feature`)
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="invoices" type="array" optional>
  Invoices for this entity (only included when `expand=invoices`)
  
  <Expandable title="Invoice object">
    <ResponseField name="id" type="string">
      Invoice ID
    </ResponseField>
    
    <ResponseField name="amount" type="number">
      Invoice amount in cents
    </ResponseField>
    
    <ResponseField name="status" type="string">
      Invoice status (paid, pending, etc.)
    </ResponseField>
    
    <ResponseField name="created_at" type="number">
      Unix timestamp when invoice was created
    </ResponseField>
  </Expandable>
</ResponseField>

## Example Request

### Basic Request

<CodeGroup>
```bash cURL
curl https://api.autumnhq.com/v1/customers/cus_123/entities/user_001 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```typescript TypeScript
const response = await fetch(
  'https://api.autumnhq.com/v1/customers/cus_123/entities/user_001',
  {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);

const data = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://api.autumnhq.com/v1/customers/cus_123/entities/user_001',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)

data = response.json()
```
</CodeGroup>

### With Expansions

<CodeGroup>
```bash cURL
curl "https://api.autumnhq.com/v1/customers/cus_123/entities/user_001?expand=invoices,balances.feature" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```typescript TypeScript
const params = new URLSearchParams({
  expand: 'invoices,balances.feature'
});

const response = await fetch(
  `https://api.autumnhq.com/v1/customers/cus_123/entities/user_001?${params}`,
  {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);

const data = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://api.autumnhq.com/v1/customers/cus_123/entities/user_001',
    headers={'Authorization': 'Bearer YOUR_API_KEY'},
    params={'expand': 'invoices,balances.feature'}
)

data = response.json()
```
</CodeGroup>

## Notes

- Use the `expand` parameter to reduce the number of API calls needed to fetch related data
- Multiple expansions can be specified by separating them with commas
- The `skip_cache` parameter is useful when you need the most up-to-date data
- Expanding resources may increase response time depending on the amount of related data
