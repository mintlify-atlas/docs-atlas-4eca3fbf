## Overview

Retrieve a list of all entities associated with a specific customer. Entities represent individual instances of metered features, such as users, projects, or API keys.

## Endpoint

```
GET /customers/{customer_id}/entities
```

## Path Parameters

<ParamField path="customer_id" type="string" required>
  The unique identifier of the customer whose entities you want to retrieve
</ParamField>

## Response

Returns an object containing a list of entity objects.

<ResponseField name="list" type="array">
  Array of entity objects
  
  <Expandable title="Entity object">
    <ResponseField name="id" type="string">
      The unique identifier of the entity
    </ResponseField>
    
    <ResponseField name="name" type="string">
      The name of the entity
    </ResponseField>
    
    <ResponseField name="customer_id" type="string">
      The customer ID this entity belongs to
    </ResponseField>
    
    <ResponseField name="feature_id" type="string">
      The feature ID this entity belongs to
    </ResponseField>
    
    <ResponseField name="created_at" type="number">
      Unix timestamp when the entity was created
    </ResponseField>
    
    <ResponseField name="env" type="string">
      The environment (sandbox/live)
    </ResponseField>
    
    <ResponseField name="autumn_id" type="string" optional>
      Internal Autumn identifier (only included when `with_autumn_id=true`)
    </ResponseField>
    
    <ResponseField name="subscriptions" type="array" optional>
      Plans associated with this entity (when expanded)
    </ResponseField>
    
    <ResponseField name="scheduled_subscriptions" type="array">
      Scheduled subscriptions for this entity
    </ResponseField>
    
    <ResponseField name="balances" type="object" optional>
      Features associated with this entity (when expanded)
    </ResponseField>
    
    <ResponseField name="invoices" type="array" optional>
      Invoices for this entity (only included when `expand=invoices`)
    </ResponseField>
  </Expandable>
</ResponseField>

## Example Request

<CodeGroup>
```bash cURL
curl https://api.autumnhq.com/v1/customers/cus_123/entities \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```typescript TypeScript
const response = await fetch(
  'https://api.autumnhq.com/v1/customers/cus_123/entities',
  {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);

const data = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://api.autumnhq.com/v1/customers/cus_123/entities',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)

data = response.json()
```
</CodeGroup>
