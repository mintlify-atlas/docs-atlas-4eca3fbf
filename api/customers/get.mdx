## Overview

Retrieve detailed information about a specific customer, including their active subscriptions, balances, and optionally expanded data like invoices and entities.

## Endpoint

```
GET /customers/{customer_id}
```

## Authentication

This endpoint requires authentication. Include your API key in the `Authorization` header:

```
Authorization: Bearer YOUR_API_KEY
```

## Request

### Path Parameters

<ParamField path="customer_id" type="string" required>
  The customer's unique identifier. This can be either your custom customer ID or Autumn's internal ID.
</ParamField>

### Query Parameters

<ParamField query="expand" type="string[]">
  Array of fields to expand in the response. Options:
  - `invoices` - Include customer invoices
  - `entities` - Include related entities
  - `trials_used` - Include trial usage history
  - `rewards` - Include referral rewards
  - `referrals` - Include referrals made by this customer
  - `payment_method` - Include payment method details
  
  Example: `?expand=invoices,entities`
</ParamField>

## Response

### Success Response (200)

Returns the full customer object.

<ResponseField name="id" type="string | null">
  Your unique identifier for the customer.
</ResponseField>

<ResponseField name="name" type="string | null">
  Customer's name.
</ResponseField>

<ResponseField name="email" type="string | null">
  Customer's email address.
</ResponseField>

<ResponseField name="created_at" type="number">
  Unix timestamp when the customer was created.
</ResponseField>

<ResponseField name="fingerprint" type="string | null">
  Unique device identifier used to prevent trial abuse.
</ResponseField>

<ResponseField name="stripe_id" type="string | null">
  Stripe customer ID if using Stripe for payments.
</ResponseField>

<ResponseField name="env" type="enum">
  Environment: `production` or `development`.
</ResponseField>

<ResponseField name="metadata" type="object">
  Custom metadata attached to the customer.
</ResponseField>

<ResponseField name="send_email_receipts" type="boolean">
  Whether email receipts are enabled for this customer.
</ResponseField>

<ResponseField name="subscriptions" type="array">
  Array of active subscription objects for this customer. Each subscription contains plan details, pricing, and current period information.
</ResponseField>

<ResponseField name="scheduled_subscriptions" type="array">
  Array of future scheduled subscriptions that will become active at a specified time.
</ResponseField>

<ResponseField name="balances" type="object">
  Credit balances by feature ID. Keys are feature IDs, values are balance objects containing:
  - Current balance amount
  - Usage information
  - Reset date if applicable
  - Rollover settings
</ResponseField>

<ResponseField name="invoices" type="array">
  **Expanded field** - Array of invoice objects for this customer. Only included when `expand=invoices` is specified.
</ResponseField>

<ResponseField name="entities" type="array">
  **Expanded field** - Array of entity objects related to this customer. Only included when `expand=entities` is specified.
</ResponseField>

<ResponseField name="trials_used" type="array">
  **Expanded field** - Array of trials this customer has used. Only included when `expand=trials_used` is specified.
</ResponseField>

<ResponseField name="rewards" type="object">
  **Expanded field** - Referral rewards information. Only included when `expand=rewards` is specified.
</ResponseField>

<ResponseField name="referrals" type="array">
  **Expanded field** - Array of referrals made by this customer. Only included when `expand=referrals` is specified.
</ResponseField>

<ResponseField name="payment_method" type="object">
  **Expanded field** - Payment method details. Only included when `expand=payment_method` is specified.
</ResponseField>

## Examples

### Request Example

<CodeGroup>

```bash cURL
curl -X GET https://api.autumnhq.com/v1/customers/user_123?expand=invoices,entities \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```typescript TypeScript
import { AutumnClient } from '@useautumn/autumn-js';

const autumn = new AutumnClient({
  apiKey: 'YOUR_API_KEY'
});

const customer = await autumn.customers.get('user_123', {
  expand: ['invoices', 'entities']
});

console.log(`Customer: ${customer.name}`);
console.log(`Active subscriptions: ${customer.subscriptions.length}`);
console.log(`Invoices: ${customer.invoices?.length || 0}`);
```

```python Python
from autumn import AutumnClient

autumn = AutumnClient(api_key='YOUR_API_KEY')

customer = autumn.customers.get(
    'user_123',
    expand=['invoices', 'entities']
)

print(f"Customer: {customer['name']}")
print(f"Active subscriptions: {len(customer['subscriptions'])}")
print(f"Invoices: {len(customer.get('invoices', []))}")
```

</CodeGroup>

## Error Handling

### Common Errors

- **400 Bad Request**: Invalid request parameters (e.g., invalid expand options)
- **401 Unauthorized**: Invalid or missing API key
- **404 Not Found**: Customer with the specified ID does not exist
- **500 Internal Server Error**: Something went wrong on the server

### Handling Missing Customers

When a customer doesn't exist, you'll receive a 404 error:

```typescript
try {
  const customer = await autumn.customers.get('nonexistent_id');
} catch (error) {
  if (error.status === 404) {
    console.log('Customer not found');
    // Create the customer or handle the missing customer case
  }
}
```

### Using Expand Efficiently

Only expand the fields you need to minimize response size and improve performance:

```typescript
// ❌ Don't expand everything unnecessarily
const customer = await autumn.customers.get('user_123', {
  expand: ['invoices', 'entities', 'trials_used', 'rewards', 'referrals', 'payment_method']
});

// ✅ Only expand what you need
const customer = await autumn.customers.get('user_123', {
  expand: ['invoices'] // Only fetch invoices
});
```
