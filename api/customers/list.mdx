## Overview

Retrieve a paginated list of all customers in your account. You can filter customers by plan subscriptions, search by customer details, and control pagination.

## Endpoint

```
POST /customers/list
```

## Authentication

This endpoint requires authentication. Include your API key in the `Authorization` header:

```
Authorization: Bearer YOUR_API_KEY
```

## Request

### Body Parameters

<ParamField body="offset" type="number" default="0">
  Number of items to skip before returning results. Use for pagination.
</ParamField>

<ParamField body="limit" type="number" default="10">
  Number of items to return per page. Default is 10, maximum is 1000.
</ParamField>

<ParamField body="plans" type="array">
  Filter customers by active plan subscriptions. Each object contains:
  - `id` (string, required): The plan ID
  - `versions` (number[], optional): Specific plan versions to filter by
  
  Example: `[{ "id": "pro-plan", "versions": [1, 2] }]`
</ParamField>

<ParamField body="subscription_status" type="enum">
  Filter by customer product status. Options:
  - `active` - Customers with active subscriptions
  - `scheduled` - Customers with scheduled subscriptions
  
  Defaults to returning both active and scheduled.
</ParamField>

<ParamField body="search" type="string">
  Search customers by ID, name, or email. Performs a case-insensitive partial match.
</ParamField>

## Response

### Success Response (200)

<ResponseField name="list" type="array">
  Array of customer objects matching the query.
  
  <ResponseField name="list[].id" type="string | null">
    Your unique identifier for the customer.
  </ResponseField>
  
  <ResponseField name="list[].name" type="string | null">
    Customer's name.
  </ResponseField>
  
  <ResponseField name="list[].email" type="string | null">
    Customer's email address.
  </ResponseField>
  
  <ResponseField name="list[].created_at" type="number">
    Unix timestamp when the customer was created.
  </ResponseField>
  
  <ResponseField name="list[].fingerprint" type="string | null">
    Unique device identifier used to prevent trial abuse.
  </ResponseField>
  
  <ResponseField name="list[].stripe_id" type="string | null">
    Stripe customer ID if using Stripe for payments.
  </ResponseField>
  
  <ResponseField name="list[].env" type="enum">
    Environment: `production` or `development`.
  </ResponseField>
  
  <ResponseField name="list[].metadata" type="object">
    Custom metadata attached to the customer.
  </ResponseField>
  
  <ResponseField name="list[].send_email_receipts" type="boolean">
    Whether to send email receipts to this customer.
  </ResponseField>
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Whether more results exist after this page. Use to determine if you should fetch the next page.
</ResponseField>

<ResponseField name="offset" type="number">
  Current offset position in the result set.
</ResponseField>

<ResponseField name="limit" type="number">
  Number of items per page as specified in the request.
</ResponseField>

<ResponseField name="total" type="number">
  Total number of items returned in the current page.
</ResponseField>

## Examples

### Request Example

<CodeGroup>

```bash cURL
curl -X POST https://api.autumnhq.com/v1/customers/list \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "limit": 50,
    "offset": 0,
    "search": "john",
    "subscription_status": "active"
  }'
```

```typescript TypeScript
import { AutumnClient } from '@useautumn/autumn-js';

const autumn = new AutumnClient({
  apiKey: 'YOUR_API_KEY'
});

const customers = await autumn.customers.list({
  limit: 50,
  offset: 0,
  search: 'john',
  subscription_status: 'active'
});

console.log(`Found ${customers.list.length} customers`);
console.log(`Has more: ${customers.has_more}`);
```

```python Python
from autumn import AutumnClient

autumn = AutumnClient(api_key='YOUR_API_KEY')

customers = autumn.customers.list(
    limit=50,
    offset=0,
    search='john',
    subscription_status='active'
)

print(f"Found {len(customers['list'])} customers")
print(f"Has more: {customers['has_more']}")
```

## Error Handling

### Common Errors

- **400 Bad Request**: Invalid request parameters (e.g., limit exceeds maximum)
- **401 Unauthorized**: Invalid or missing API key
- **500 Internal Server Error**: Something went wrong on the server

### Pagination Best Practices

To paginate through all customers:

1. Start with `offset: 0`
2. Check the `has_more` field in the response
3. If `has_more` is `true`, increment offset by the limit and make another request
4. Continue until `has_more` is `false`

```typescript
let offset = 0;
const limit = 100;
const allCustomers = [];

while (true) {
  const response = await autumn.customers.list({ limit, offset });
  allCustomers.push(...response.list);
  
  if (!response.has_more) break;
  offset += limit;
}
```
