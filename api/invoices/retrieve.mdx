---
title: "Get Invoice"
api: "GET /invoices/{stripe_invoice_id}/stripe"
description: "Retrieve a specific invoice from Stripe"
---

Retrieve the full details of a specific invoice directly from Stripe using its Stripe invoice ID. This returns the complete Stripe invoice object with all available fields.

## Request

<ParamField path="stripe_invoice_id" type="string" required>
  The Stripe invoice ID (e.g., `in_1A2B3C4D5E6F7G8H`). This is the `stripe_id` field from the invoice list response.
</ParamField>

## Response

Returns a complete Stripe invoice object. For detailed information about all available fields, see the [Stripe Invoice API documentation](https://stripe.com/docs/api/invoices/object).

<ResponseField name="id" type="string">
  The Stripe invoice ID.
</ResponseField>

<ResponseField name="amount_due" type="number">
  Final amount due at this time for this invoice in the smallest currency unit.
</ResponseField>

<ResponseField name="amount_paid" type="number">
  The amount that was paid.
</ResponseField>

<ResponseField name="amount_remaining" type="number">
  The amount remaining to be paid.
</ResponseField>

<ResponseField name="currency" type="string">
  Three-letter ISO currency code.
</ResponseField>

<ResponseField name="customer" type="string">
  The Stripe customer ID.
</ResponseField>

<ResponseField name="status" type="string">
  The status of the invoice: `draft`, `open`, `paid`, `void`, or `uncollectible`.
</ResponseField>

<ResponseField name="created" type="number">
  Unix timestamp when the invoice was created.
</ResponseField>

<ResponseField name="hosted_invoice_url" type="string">
  The URL for the hosted invoice page.
</ResponseField>

<ResponseField name="lines" type="object">
  The individual line items that make up the invoice.
</ResponseField>

<ResponseField name="metadata" type="object">
  Set of key-value pairs that you can attach to an object.
</ResponseField>

## Code Examples

<CodeGroup>
```typescript TypeScript
const stripeInvoiceId = 'in_1A2B3C4D5E6F7G8H';

const response = await fetch(
  `https://api.autumn.com/v1/invoices/${stripeInvoiceId}/stripe`,
  {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    }
  }
);

const invoice = await response.json();
console.log(`Amount due: $${invoice.amount_due / 100}`);
console.log(`Status: ${invoice.status}`);
console.log(`Line items:`, invoice.lines.data);
```

```python Python
import requests

stripe_invoice_id = 'in_1A2B3C4D5E6F7G8H'

response = requests.get(
    f'https://api.autumn.com/v1/invoices/{stripe_invoice_id}/stripe',
    headers={
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    }
)

invoice = response.json()
print(f"Amount due: ${invoice['amount_due'] / 100}")
print(f"Status: {invoice['status']}")
print(f"Line items: {invoice['lines']['data']}")
```

```bash cURL
curl -X GET "https://api.autumn.com/v1/invoices/in_1A2B3C4D5E6F7G8H/stripe" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```
</CodeGroup>

## Error Handling

<ResponseField name="400" type="error">
  **Bad Request** - Invalid Stripe invoice ID format.
</ResponseField>

<ResponseField name="401" type="error">
  **Unauthorized** - Invalid or missing API key.
</ResponseField>

<ResponseField name="404" type="error">
  **Not Found** - Invoice with the specified Stripe ID does not exist.
</ResponseField>

<ResponseField name="500" type="error">
  **Internal Server Error** - An unexpected error occurred on the server or while communicating with Stripe.
</ResponseField>
