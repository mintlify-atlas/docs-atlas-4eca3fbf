## Overview

Retrieve a list of all features in your account. This includes metered features, credit systems, and boolean features. By default, archived features are excluded from the results.

## Endpoint

```
GET /features
```

## Authentication

This endpoint requires authentication. Include your API key in the `Authorization` header:

```
Authorization: Bearer YOUR_API_KEY
```

## Request

No parameters required. This endpoint returns all active (non-archived) features.

## Response

### Success Response (200)

Returns an object containing an array of features.

<ResponseField name="list" type="array">
  Array of feature objects.
  
  <Expandable title="Feature Object">
    <ResponseField name="id" type="string">
      The unique identifier for the feature.
    </ResponseField>
    
    <ResponseField name="name" type="string">
      The human-readable name of the feature.
    </ResponseField>
    
    <ResponseField name="type" type="enum">
      The feature type: `metered`, `credit_system`, or `boolean`.
    </ResponseField>
    
    <ResponseField name="consumable" type="boolean">
      Whether the feature is consumable. Only present for metered features.
    </ResponseField>
    
    <ResponseField name="credit_schema" type="array">
      Credit conversion schema. Only present for credit_system features.
    </ResponseField>
    
    <ResponseField name="display" type="object">
      Display names for the feature (singular and plural).
    </ResponseField>
    
    <ResponseField name="event_names" type="array">
      Array of event names that trigger usage tracking.
    </ResponseField>
    
    <ResponseField name="archived" type="boolean">
      Whether the feature is archived.
    </ResponseField>
  </Expandable>
</ResponseField>

### List All Features

<CodeGroup>

```bash cURL
curl -X GET https://api.autumnhq.com/v1/features \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```typescript TypeScript
import { AutumnClient } from '@useautumn/autumn-js';

const autumn = new AutumnClient({
```

## Use Cases

### Display Available Features

List all features in your dashboard or admin interface:

```typescript
const { list } = await autumn.features.list();

// Group features by type
const metered = list.filter(f => f.type === 'metered');
const credits = list.filter(f => f.type === 'credit_system');
const boolean = list.filter(f => f.type === 'boolean');

console.log('Metered Features:', metered.map(f => f.name));
console.log('Credit Systems:', credits.map(f => f.name));
console.log('Boolean Features:', boolean.map(f => f.name));
```

### Filter by Feature Type

Get only specific types of features:

```typescript
const { list } = await autumn.features.list();

// Get only consumable metered features
const consumableFeatures = list.filter(f => 
  f.type === 'metered' && f.consumable === true
);

console.log('Consumable features:', consumableFeatures);
```

### Validate Credit System Dependencies

Check which metered features are used in credit systems:

```typescript
const { list } = await autumn.features.list();

const creditSystems = list.filter(f => f.type === 'credit_system');

for (const creditSystem of creditSystems) {
  console.log(`\nCredit system: ${creditSystem.name}`);
  console.log('Uses these metered features:');
  
  creditSystem.credit_schema.forEach(item => {
    const feature = list.find(f => f.id === item.metered_feature_id);
    console.log(`  - ${feature?.name} (${item.credit_cost} credits)`);
  });
}
```

### Build Feature Selector

Create a UI component for selecting features:

```typescript
interface FeatureOption {
  value: string;
  label: string;
  type: string;
}

const { list } = await autumn.features.list();

const featureOptions: FeatureOption[] = list.map(feature => ({
  value: feature.id,
  label: feature.name,
  type: feature.type
}));

// Use in a select dropdown
console.log('Feature options:', featureOptions);
```

### Find Features by Event Name

Discover which features are triggered by specific events:

```typescript
const { list } = await autumn.features.list();
const eventName = 'api_call';

const featuresForEvent = list.filter(f => 
  f.event_names?.includes(eventName)
);

console.log(`Features tracking "${eventName}":`, 
  featuresForEvent.map(f => f.name)
);
```

### Audit Feature Configuration

Review all features for completeness:

```typescript
const { list } = await autumn.features.list();

// Check for features without display names
const missingDisplay = list.filter(f => 
  !f.display?.singular || !f.display?.plural
);

if (missingDisplay.length > 0) {
  console.log('⚠️ Features missing display names:');
  missingDisplay.forEach(f => console.log(`  - ${f.id}`));
}

// Check for metered features without event names
const missingEvents = list.filter(f => 
  f.type === 'metered' && (!f.event_names || f.event_names.length === 0)
);

if (missingEvents.length > 0) {
  console.log('⚠️ Metered features without event names:');
  missingEvents.forEach(f => console.log(`  - ${f.id}`));
}
```

### Generate Feature Documentation

Create documentation from your feature configuration:

```typescript
const { list } = await autumn.features.list();

console.log('# Features\n');

list.forEach(feature => {
  console.log(`## ${feature.name}`);
  console.log(`**ID:** \`${feature.id}\``);
  console.log(`**Type:** ${feature.type}`);
  
  if (feature.type === 'metered') {
    console.log(`**Consumable:** ${feature.consumable ? 'Yes' : 'No'}`);
  }
  
  if (feature.display) {
    console.log(`**Display:** ${feature.display.singular} / ${feature.display.plural}`);
  }
  
  if (feature.event_names && feature.event_names.length > 0) {
    console.log(`**Events:** ${feature.event_names.join(', ')}`);
  }
  
  if (feature.type === 'credit_system' && feature.credit_schema) {
    console.log('**Credit Schema:**');
    feature.credit_schema.forEach(item => {
      console.log(`  - ${item.metered_feature_id}: ${item.credit_cost} credits`);
    });
  }
  
  console.log('');
});
```

## Filtering and Sorting

### Filter Archived Features

By default, archived features are excluded. If you need to see them, you'll need to check the `archived` field after retrieving:

```typescript
const { list } = await autumn.features.list();

// Explicitly filter archived features
const active = list.filter(f => !f.archived);
const archived = list.filter(f => f.archived);

console.log(`Active: ${active.length}, Archived: ${archived.length}`);
```

### Sort Features

Sort features by various criteria:

```typescript
const { list } = await autumn.features.list();

// Sort alphabetically by name
const byName = [...list].sort((a, b) => 
  a.name.localeCompare(b.name)
);

// Sort by type
const byType = [...list].sort((a, b) => 
  a.type.localeCompare(b.type)
);

// Sort consumable features first
const byConsumable = [...list].sort((a, b) => {
  if (a.consumable === b.consumable) return 0;
  return a.consumable ? -1 : 1;
});
```

## Performance Considerations

The list endpoint returns all features in a single response. For accounts with many features:

- **Caching**: Cache the response on the client side if features don't change frequently
- **Pagination**: Not currently supported, but all features are returned in one call
- **Filtering**: Filter and sort on the client side after retrieval

```typescript Example: Client-side caching
let cachedFeatures = null;
let cacheTimestamp = 0;
const CACHE_DURATION = 5 * 60 * 1000; // 5 minutes

async function getFeatures() {
  const now = Date.now();
  
  if (cachedFeatures && (now - cacheTimestamp) < CACHE_DURATION) {
    return cachedFeatures;
  }
  
  const response = await autumn.features.list();
  cachedFeatures = response.list;
  cacheTimestamp = now;
  
  return cachedFeatures;
}
```
