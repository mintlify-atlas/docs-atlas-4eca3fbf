---
title: "Get Event"
api: "GET /events/{event_id}"
description: "Retrieve a specific event by its ID"
---

Retrieve detailed information about a specific event using its unique identifier. Events represent feature usage tracked in your system.

## Request

<ParamField path="event_id" type="string" required>
  The unique identifier of the event (KSUID format). Example: `evt_36xpk2TmuQX5zVPPQ8tCtnR5Weg`
</ParamField>

## Response

<ResponseField name="id" type="string">
  Unique event identifier (KSUID format).
</ResponseField>

<ResponseField name="timestamp" type="number">
  Event timestamp in Unix epoch milliseconds.
</ResponseField>

<ResponseField name="feature_id" type="string">
  The ID of the feature that this event belongs to.
</ResponseField>

<ResponseField name="customer_id" type="string">
  The customer identifier who triggered this event.
</ResponseField>

<ResponseField name="value" type="number">
  The event value or count. Represents the amount of usage for this event.
</ResponseField>

<ResponseField name="properties" type="object">
  Additional event properties stored as a JSON object. Contains custom metadata attached to the event.
</ResponseField>

<ResponseField name="created_at" type="number">
  Unix timestamp (milliseconds) when the event was created in the system.
</ResponseField>

<ResponseField name="idempotency_key" type="string | null">
  Optional idempotency key used to prevent duplicate events.
</ResponseField>

## Code Examples

<CodeGroup>
```typescript TypeScript
const eventId = 'evt_36xpk2TmuQX5zVPPQ8tCtnR5Weg';

const response = await fetch(
  `https://api.autumn.com/v1/events/${eventId}`,
  {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    }
  }
);

const event = await response.json();
console.log(`Event ${event.id}`);
console.log(`Customer: ${event.customer_id}`);
console.log(`Feature: ${event.feature_id}`);
console.log(`Value: ${event.value}`);
```

```python Python
import requests

event_id = 'evt_36xpk2TmuQX5zVPPQ8tCtnR5Weg'

response = requests.get(
    f'https://api.autumn.com/v1/events/{event_id}',
    headers={
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    }
)

event = response.json()
print(f"Event {event['id']}")
print(f"Customer: {event['customer_id']}")
print(f"Feature: {event['feature_id']}")
print(f"Value: {event['value']}")
```

```bash cURL
curl -X GET "https://api.autumn.com/v1/events/evt_36xpk2TmuQX5zVPPQ8tCtnR5Weg" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

## Error Handling

<ResponseField name="400" type="error">
  **Bad Request** - Invalid event ID format.
</ResponseField>

<ResponseField name="401" type="error">
  **Unauthorized** - Invalid or missing API key.
</ResponseField>

<ResponseField name="404" type="error">
  **Not Found** - Event with the specified ID does not exist.
</ResponseField>

<ResponseField name="500" type="error">
  **Internal Server Error** - An unexpected error occurred on the server.
</ResponseField>
