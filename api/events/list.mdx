---
title: "List Events"
api: "POST /events/list"
description: "Retrieve a paginated list of events with optional filtering"
---

Retrieve a list of usage events tracked in your system. Events represent feature usage and are typically created via the `/track` endpoint. You can filter events by customer, feature, and time range.

## Request

<ParamField body="offset" type="number" default="0">
  The number of events to skip for pagination. Use with `limit` to paginate through results.
</ParamField>

<ParamField body="limit" type="number" default="100">
  The maximum number of events to return. Maximum value is 1000.
</ParamField>

<ParamField body="customer_id" type="string">
  Filter events by customer ID. Only returns events for the specified customer.
</ParamField>

<ParamField body="feature_id" type="string | string[]">
  Filter events by specific feature ID(s). Can be a single feature ID string or an array of feature IDs.
</ParamField>

<ParamField body="custom_range" type="object">
  Filter events by a custom time range.

  <Expandable title="Custom Range Object">
    <ParamField body="start" type="number">
      Filter events after this timestamp (epoch milliseconds). Events with timestamps greater than or equal to this value will be included.
    </ParamField>

    <ParamField body="end" type="number">
      Filter events before this timestamp (epoch milliseconds). Events with timestamps less than or equal to this value will be included.
    </ParamField>
  </Expandable>
</ParamField>

## Response

<ResponseField name="list" type="array">
  An array of event objects matching the filter criteria.

  <Expandable title="Event Object">
    <ResponseField name="id" type="string">
      Unique event identifier (KSUID format).
    </ResponseField>

    <ResponseField name="timestamp" type="number">
      Event timestamp in Unix epoch milliseconds.
    </ResponseField>

    <ResponseField name="feature_id" type="string">
      The ID of the feature that this event belongs to.
    </ResponseField>

    <ResponseField name="customer_id" type="string">
      The customer identifier who triggered this event.
    </ResponseField>

    <ResponseField name="value" type="number">
      The event value or count. Represents the amount of usage for this event.
    </ResponseField>

    <ResponseField name="properties" type="object">
      Additional event properties stored as a JSON object. Contains custom metadata attached to the event.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="number">
  The number of events returned in this response.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Indicates whether more events exist beyond the current page. Use this to determine if you should fetch the next page.
</ResponseField>

<ResponseField name="offset" type="number">
  The offset value used for this request.
</ResponseField>

<ResponseField name="limit" type="number">
  The limit value used for this request.
</ResponseField>

## Code Examples

<CodeGroup>
```typescript TypeScript
// List all events for a customer
const response = await fetch('https://api.autumn.com/v1/events/list', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    customer_id: 'cus_123',
    limit: 50
  })
});

const data = await response.json();
console.log(`Retrieved ${data.total} events`);
console.log(`Has more: ${data.has_more}`);

// Paginate through events
let offset = 0;
const limit = 100;
let hasMore = true;

while (hasMore) {
  const response = await fetch('https://api.autumn.com/v1/events/list', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      customer_id: 'cus_123',
      offset,
      limit
    })
  });
  
  const data = await response.json();
  console.log(`Fetched ${data.list.length} events`);
  
  hasMore = data.has_more;
  offset += limit;
}
```

```python Python
import requests

# List all events for a customer
response = requests.post(
    'https://api.autumn.com/v1/events/list',
    headers={
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    },
    json={
        'customer_id': 'cus_123',
        'limit': 50
    }
)

data = response.json()
print(f"Retrieved {data['total']} events")
print(f"Has more: {data['has_more']}")

# Filter by time range and feature
response = requests.post(
    'https://api.autumn.com/v1/events/list',
    headers={
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    },
    json={
        'customer_id': 'cus_123',
        'feature_id': 'api_calls',
        'custom_range': {
            'start': 1704067200000,  # Jan 1, 2024
            'end': 1735689600000     # Jan 1, 2025
        }
    }
)

data = response.json()
for event in data['list']:
    print(f"Event {event['id']}: {event['value']} at {event['timestamp']}")
```

## Error Handling

<ResponseField name="400" type="error">
  **Bad Request** - Invalid parameters. Common causes:
  - Invalid timestamp format in custom_range
  - Limit exceeds maximum value (1000)
  - Invalid feature_id format
</ResponseField>

<ResponseField name="401" type="error">
  **Unauthorized** - Invalid or missing API key.
</ResponseField>

<ResponseField name="404" type="error">
  **Not Found** - The specified customer or feature does not exist.
</ResponseField>

<ResponseField name="500" type="error">
  **Internal Server Error** - An unexpected error occurred on the server.
</ResponseField>
