## Overview

Subscription pricing charges customers a recurring fee at regular intervals. This is the most common pricing model for SaaS businesses, providing predictable revenue and ongoing customer relationships.

**Common use cases:**
- Monthly or annual SaaS subscriptions
- Service plans with recurring fees
- Membership programs
- Support and maintenance contracts

## How Subscriptions Work

Subscriptions consist of:
- **Base price** - The recurring charge amount
- **Billing interval** - How often customers are charged (week, month, year)
- **Renewal** - Automatic rebilling at the end of each period
- **Proration** - Handling mid-cycle changes

```typescript
{
  type: "price",
  price: 2900,            // $29.00
  interval: "month"       // Billed monthly
}
```

## Creating Subscription Products

<Steps>
  <Step title="Define your product">
    Create a product with a recurring base price:

    ```typescript
    const product = await autumn.products.create({
      id: "pro_plan",
      name: "Pro Plan",
      description: "Full access to all features",
      is_add_on: false,
      items: [
        {
          type: "price",
          price: 2900,         // $29.00 per month
          interval: "month"
        }
      ]
    });
    ```

    <Info>Learn more about [Products and Plans](/concepts/products-and-plans)</Info>
  </Step>

  <Step title="Subscribe a customer">
    Use the `/attach` endpoint to create a subscription:

    ```typescript
    const subscription = await autumn.attach({
      customer_id: "customer_123",
      product_id: "pro_plan"
    });
    ```

    The subscription activates immediately and renews automatically.

    <Info>Learn more about the [Attach API](/api-reference/core/attach)</Info>
  </Step>

  <Step title="Collect payment (optional)">
    For customers without payment methods, redirect to checkout:

    ```typescript
    const checkout = await autumn.attach({
      customer_id: "customer_123",
      product_id: "pro_plan",
      success_url: "https://yourapp.com/success"
    });

    // Redirect to checkout.url
    window.location.href = checkout.url;
    ```

    <Info>Learn more about the [Checkout flow](/guides/attach-products)</Info>
  </Step>
</Steps>

## Billing Intervals

Autumn supports multiple billing intervals with flexible counts:

### Monthly Subscriptions

```typescript
{
  type: "price",
  price: 2900,           // $29.00
  interval: "month",
  interval_count: 1
}
```

Charges customers every month on the same day they subscribed.

### Annual Subscriptions

```typescript
{
  type: "price",
  price: 29900,          // $299.00
  interval: "year",
  interval_count: 1
}
```

Charges once per year, often offered at a discount (e.g., 2 months free).

### Quarterly Subscriptions

```typescript
{
  type: "price",
  price: 8700,           // $87.00
  interval: "month",
  interval_count: 3      // Every 3 months
}
```

Charges every 3 months, balancing commitment and flexibility.

### Weekly Subscriptions

```typescript
{
  type: "price",
  price: 700,            // $7.00
  interval: "week",
  interval_count: 1
}
```

Useful for short-term services or trials.

### Custom Intervals

Use `interval_count` for any custom period:

```typescript
{
  type: "price",
  price: 17900,
  interval: "month",
  interval_count: 6      // Every 6 months
}
```

## Multiple Billing Options

Offer customers a choice between different billing intervals using product groups:

```typescript
const proMonthly = await autumn.products.create({
  id: "pro_monthly",
  name: "Pro Plan",
  group: "pro",           // Group related products
  items: [
    {
      type: "price",
      price: 2900,
      interval: "month"
    }
  ]
});

const proAnnual = await autumn.products.create({
  id: "pro_annual",
  name: "Pro Plan (Annual)",
  group: "pro",
  items: [
    {
      type: "price",
      price: 29900,        // ~16% discount
      interval: "year"
    }
  ]
});
```

<Tip>
Use the `group` field to associate monthly and annual versions of the same plan for seamless upgrades.
</Tip>

## Free Trials

Offer trial periods before billing begins:

```typescript
const product = await autumn.products.create({
  id: "pro_with_trial",
  name: "Pro Plan",
  free_trial: {
    duration: "day",
    length: 14,              // 14 days
    card_required: true,     // Require payment method
    unique_fingerprint: false
  },
  items: [
    {
      type: "price",
      price: 2900,
      interval: "month"
    }
  ]
});
```

Customers get full access during the trial. Billing starts automatically when the trial ends.

<Info>
Customers can cancel anytime during the trial without being charged.
</Info>

## Upgrades and Downgrades

### Upgrading Plans

Move customers to a higher-priced plan:

```typescript
await autumn.attach({
  customer_id: "customer_123",
  product_id: "pro_plan"  // Higher tier
});
```

By default, upgrades:
- Take effect immediately
- Are prorated based on time remaining in the period
- Credit the unused portion of the old plan

### Downgrading Plans

```typescript
await autumn.attach({
  customer_id: "customer_123",
  product_id: "starter_plan"  // Lower tier
});
```

By default, downgrades:
- Take effect at the end of the current billing period
- Don't charge prorated amounts immediately
- Preserve access until the period ends

### Proration Behavior

Control how mid-cycle changes are handled:

```typescript
// Configure proration on product items
{
  type: "price",
  price: 4900,
  interval: "month",
  config: {
    on_increase: "prorate_immediately",  // Bill upgrades now
    on_decrease: "prorate_next_cycle"    // Apply downgrades later
  }
}
```

**Proration options for upgrades (`on_increase`):**
- `prorate_immediately` - Charge prorated difference now (default)
- `bill_immediately` - Charge full new price now
- `prorate_next_cycle` - Apply at next renewal
- `bill_next_cycle` - Apply at next renewal

**Proration options for downgrades (`on_decrease`):**
- `prorate_next_cycle` - Apply at next renewal (default)
- `prorate_immediately` - Credit difference now
- `none` - No proration

## Checking Subscription Access

Verify a customer's subscription status before granting access:

```typescript
const check = await autumn.check({
  customer_id: "customer_123",
  product_id: "pro_plan"
});

if (!check.has_access) {
  // Customer doesn't have active subscription
  return { error: "Subscription required" };
}

// Grant access to feature
```

<Info>Learn more about the [Check API](/api-reference/core/check)</Info>

## Dashboard Configuration

Create subscription products in the Autumn dashboard:

1. Navigate to **Products** → **Create Product**
2. Enter product ID, name, and description
3. Under **Items**, click **Add Item**
4. Select **Price**
5. Enter the price amount (in cents)
6. Choose billing interval (month, year, week)
7. Optionally configure a free trial
8. Save the product

<Tip>
You can create multiple versions of the same product with different billing intervals (monthly vs. annual).
</Tip>

## Common Patterns

### Good-Better-Best Tiers

```typescript
const starter = await autumn.products.create({
  id: "starter",
  name: "Starter",
  group: "main",
  items: [{ type: "price", price: 900, interval: "month" }]
});

const pro = await autumn.products.create({
  id: "pro",
  name: "Pro",
  group: "main",
  items: [{ type: "price", price: 2900, interval: "month" }]
});

const enterprise = await autumn.products.create({
  id: "enterprise",
  name: "Enterprise",
  group: "main",
  items: [{ type: "price", price: 9900, interval: "month" }]
});
```

### Base Subscription + Usage

Combine fixed recurring fees with usage-based charges:

```typescript
const hybrid = await autumn.products.create({
  id: "pro_hybrid",
  name: "Pro Plan",
  items: [
    {
      type: "price",
      price: 2900,         // $29/month base
      interval: "month"
    },
    {
      type: "priced_feature",
      feature_id: "api_calls",
      included_usage: 10000,  // 10k included
      price: 10,              // $0.10 per 1k overage
      billing_units: 1000,
      usage_model: "pay_per_use",
      interval: "month"
    }
  ]
});
```

<Info>Learn more about [Usage-Based Pricing](/pricing-models/usage-based)</Info>

### Freemium Model

```typescript
const free = await autumn.products.create({
  id: "free_plan",
  name: "Free Plan",
  is_default: true,        // Auto-assigned to new customers
  items: [
    {
      type: "feature",
      feature_id: "basic_features",
      unlimited: true
    }
  ]
});
```

## Frequently Asked Questions

<Accordion title="How do I cancel a subscription?">
  Use the cancel endpoint with the customer ID:

  ```typescript
  await autumn.cancel({
    customer_id: "customer_123",
    cancel_at_period_end: true  // Keep access until period ends
  });
  ```

  Set `cancel_at_period_end: false` to cancel immediately.
</Accordion>

<Accordion title="What happens when a payment fails?">
  Autumn automatically retries failed payments according to Stripe's retry schedule. You'll receive webhooks for:
  - `invoice.payment_failed` - Initial failure
  - `invoice.payment_action_required` - Requires customer action (e.g., 3D Secure)
  - `subscription.updated` - Status changes to `past_due`

  After all retries fail, the subscription may be canceled depending on your settings.
</Accordion>

<Accordion title="Can I change subscription prices for existing customers?">
  Yes, but it requires creating a new product version. Existing customers remain on their current pricing unless you explicitly migrate them:

  ```typescript
  // Create new version
  await autumn.products.update({
    id: "pro_plan",
    items: [{ type: "price", price: 3900, interval: "month" }]
  });

  // Migrate customer
  await autumn.attach({
    customer_id: "customer_123",
    product_id: "pro_plan"  // Uses new version
  });
  ```
</Accordion>

<Accordion title="How do I handle tax calculations?">
  Autumn integrates with Stripe Tax for automatic tax calculations. Enable it in your Stripe dashboard, and taxes will be calculated and collected automatically based on customer location.
</Accordion>

<Accordion title="Can customers switch between monthly and annual billing?">
  Yes! Place both plans in the same `group`, and use the attach endpoint to switch:

  ```typescript
  await autumn.attach({
    customer_id: "customer_123",
    product_id: "pro_annual"  // Switch to annual
  });
  ```

  Proration will be applied based on your configuration.
</Accordion>
