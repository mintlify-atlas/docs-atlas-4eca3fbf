## Overview

Credits pricing allows customers to purchase or receive prepaid balances that are consumed as they use your service. This model provides flexibility, reduces billing friction, and is ideal for unpredictable usage patterns.

**Common use cases:**
- Prepaid API credits
- Promotional credits for new customers
- Referral bonuses
- Credit packages (100, 500, 1000 credits)
- Refund credits for service issues
- Rollover allowances

## How Credits Work

Credits are managed through customer balances:

```typescript
{
  feature_id: "api_calls",
  granted: 1000,      // Total credits granted
  used: 250,          // Credits consumed
  remaining: 750      // Credits available
}
```

When you track usage, Autumn automatically deducts from the balance:

```typescript
await autumn.track({
  customer_id: "customer_123",
  feature_id: "api_calls",
  value: 1  // Uses 1 credit
});
```

## Granting Credits

<Steps>
  <Step title="Create a metered feature">
    Define what credits apply to:

    ```typescript
    const feature = await autumn.features.create({
      id: "api_calls",
      name: "API Calls",
      config: {
        usage_type: "continuous_use"
      }
    });
    ```
  </Step>

  <Step title="Create a product that grants credits">
    Grant credits by including a feature item in your product:

    ```typescript
    const creditPack = await autumn.products.create({
      id: "credit_pack_1000",
      name: "1,000 API Credits",
      items: [
        {
          type: "price",
          price: 5000,        // $50.00 one-time
          interval: null      // One-time payment
        },
        {
          type: "feature",
          feature_id: "api_calls",
          included_usage: 1000  // Grant 1,000 credits
        }
      ]
    });
    ```
  </Step>

  <Step title="Customer purchases credits">
    Use attach to grant the credits:

    ```typescript
    await autumn.attach({
      customer_id: "customer_123",
      product_id: "credit_pack_1000"
    });
    ```

    <Info>Learn more about the [Attach API](/api-reference/core/attach)</Info>
  </Step>

  <Step title="Track usage against credits">
    Usage automatically depletes the balance:

    ```typescript
    await autumn.track({
      customer_id: "customer_123",
      feature_id: "api_calls",
      value: 1
    });
    ```

    <Info>Learn more about the [Track API](/api-reference/core/track)</Info>
  </Step>
</Steps>

## Credit Products

### One-Time Credit Packages

Sell credits as one-time purchases:

```typescript
const creditPack = await autumn.products.create({
  id: "credits_1000",
  name: "1,000 API Credits",
  is_add_on: true,      // Allow multiple purchases
  items: [
    {
      type: "price",
      price: 5000,        // $50.00 one-time
      interval: null      // No recurring billing
    },
    {
      type: "feature",
      feature_id: "api_calls",
      included_usage: 1000,  // Grant 1,000 credits
      interval: null         // Credits don't expire
    }
  ]
});
```

Customers pay once and receive 1,000 credits that don't expire.

### Recurring Credit Subscriptions

Provide monthly credit allowances:

```typescript
const subscription = await autumn.products.create({
  id: "pro_monthly",
  name: "Pro Plan",
  items: [
    {
      type: "price",
      price: 2900,        // $29/month
      interval: "month"
    },
    {
      type: "feature",
      feature_id: "api_calls",
      included_usage: 10000,  // 10k credits/month
      interval: "month"       // Resets monthly
    }
  ]
});
```

Customers get 10,000 fresh credits at the start of each billing period.

### Prepaid with Overages

Combine prepaid credits with pay-per-use overages:

```typescript
const prepaidOverage = await autumn.products.create({
  id: "prepaid_plan",
  name: "Prepaid Plan",
  items: [
    {
      type: "price",
      price: 4900,
      interval: "month"
    },
    {
      type: "priced_feature",
      feature_id: "api_calls",
      included_usage: 50000,    // 50k credits included
      price: 10,                // $0.10 per 1k overage
      billing_units: 1000,
      usage_model: "pay_per_use",
      interval: "month"
    }
  ]
});
```

Customers use their 50k included credits first. Additional usage is billed at $0.10 per 1,000 calls.

## Promotional Credits

### Signup Bonuses

Grant credits to new customers:

```typescript
async function grantSignupBonus(customerId: string) {
  await autumn.balances.create({
    customer_id: customerId,
    feature_id: "api_calls",
    granted_balance: 500,
    current_balance: 500
  });
}

// On customer creation
const customer = await autumn.customers.create({
  id: "customer_123",
  name: "Acme Corp"
});

await grantSignupBonus(customer.id);
```

### Referral Credits

Reward customers for referrals:

```typescript
async function grantReferralCredit(referrerId: string) {
  await autumn.balances.update({
    customer_id: referrerId,
    feature_id: "api_calls",
    add_to_balance: 1000  // Add 1,000 bonus credits
  });
}
```

### Refund Credits

Issue credits for service issues:

```typescript
await autumn.balances.update({
  customer_id: "customer_123",
  feature_id: "api_calls",
  add_to_balance: 200
});
```

## Updating Balances

### Add Credits

```typescript
await autumn.balances.update({
  customer_id: "customer_123",
  feature_id: "api_calls",
  add_to_balance: 500  // Add 500 credits
});
```

### Set Absolute Balance

```typescript
await autumn.balances.update({
  customer_id: "customer_123",
  feature_id: "api_calls",
  current_balance: 2000  // Set to exactly 2,000
});
```

### Update Granted Balance

```typescript
await autumn.balances.update({
  customer_id: "customer_123",
  feature_id: "api_calls",
  granted_balance: 1500,   // Update total granted
  current_balance: 1500    // Reset to new amount
});
```

## Credit Reset and Expiration

### Monthly Reset

Credits that reset at the start of each period:

```typescript
{
  type: "feature",
  feature_id: "api_calls",
  included_usage: 5000,
  interval: "month"      // Resets monthly
}
```

On renewal, the balance resets to 5,000 credits.

### Never Reset (Perpetual)

Credits that don't expire:

```typescript
{
  type: "feature",
  feature_id: "api_calls",
  included_usage: 1000,
  interval: null    // Never expires
}
```

## Credit Rollover

Allow unused credits to carry over:

```typescript
const rolloverPlan = await autumn.products.create({
  id: "rollover_plan",
  name: "Rollover Plan",
  items: [
    {
      type: "price",
      price: 2900,
      interval: "month"
    },
    {
      type: "feature",
      feature_id: "api_calls",
      included_usage: 5000,
      interval: "month",
      config: {
        rollover: {
          max: 10000,          // Max 10k can accumulate
          duration: "month",
          length: 3            // Rollover expires after 3 months
        }
      }
    }
  ]
});
```

**Rollover behavior:**
- Customer gets 5,000 credits per month
- Unused credits roll over (up to 10,000 total)
- Rolled credits expire after 3 months

<Tip>
Set rollover limits to prevent unlimited credit accumulation.
</Tip>

## Checking Credit Balance

Before expensive operations, check available credits:

```typescript
const customer = await autumn.customers.retrieve({
  customer_id: "customer_123",
  expand: ["balances.feature"]
});

const balance = customer.balances?.find(
  b => b.feature_id === "api_calls"
);

if (balance && balance.remaining < 100) {
  // Warn customer they're running low
  console.log("Low balance warning");
}

if (balance && balance.remaining === 0) {
  // No credits left
  return { error: "Insufficient credits" };
}
```

### Pre-Flight Checks

```typescript
const check = await autumn.check({
  customer_id: "customer_123",
  feature_id: "api_calls",
  required_balance: 1
});

if (!check.has_access) {
  return { error: "No credits remaining" };
}

// Proceed with operation
await processRequest();

// Deduct credit
await autumn.track({
  customer_id: "customer_123",
  feature_id: "api_calls",
  value: 1
});
```

<Info>Learn more about the [Check API](/api-reference/core/check)</Info>

## Monitoring Credit Usage

Track how customers consume credits:

```typescript
const customer = await autumn.customers.retrieve({
  customer_id: "customer_123",
  expand: ["balances.feature"]
});

for (const balance of customer.balances || []) {
  const percentUsed = (balance.used / balance.granted) * 100;
  
  console.log({
    feature: balance.feature?.name,
    granted: balance.granted,
    used: balance.used,
    remaining: balance.remaining,
    percent_used: `${percentUsed.toFixed(1)}%`,
    resets_at: balance.period_end
  });
}
```

## Dashboard Configuration

### Creating Credit Packages

1. Navigate to **Products** → **Create Product**
2. Enter product ID and name (e.g., "1,000 API Credits")
3. Check **Is Add-on** to allow multiple purchases
4. Click **Add Item** → **Fixed Price**
   - Set price (e.g., $50.00)
   - Leave interval blank for one-time
5. Click **Add Item** → **Feature**
   - Select the feature (e.g., "API Calls")
   - Set **Included Usage** (e.g., 1000)
   - Leave interval blank for perpetual credits
6. Save the product

### Manually Granting Credits

1. Navigate to **Customers** → Select customer
2. Go to **Balances** tab
3. Click **Add Balance**
4. Select feature
5. Enter credit amount
6. Save

## Common Patterns

### Freemium with Trial Credits

```typescript
const freePlan = await autumn.products.create({
  id: "free_plan",
  name: "Free Plan",
  is_default: true,
  items: [
    {
      type: "feature",
      feature_id: "api_calls",
      included_usage: 1000,    // 1k free credits/month
      interval: "month"
    }
  ]
});
```

### Credit Top-Up Packages

```typescript
const topUpPackages = [
  { id: "credits_100", name: "100 Credits", price: 1000, credits: 100 },
  { id: "credits_500", name: "500 Credits", price: 4500, credits: 500 },
  { id: "credits_1000", name: "1,000 Credits", price: 8000, credits: 1000 },
  { id: "credits_5000", name: "5,000 Credits", price: 35000, credits: 5000 }
];

for (const pkg of topUpPackages) {
  await autumn.products.create({
    id: pkg.id,
    name: pkg.name,
    is_add_on: true,
    items: [
      { type: "price", price: pkg.price, interval: null },
      { 
        type: "feature",
        feature_id: "api_calls",
        included_usage: pkg.credits,
        interval: null
      }
    ]
  });
}
```

### Multi-Feature Credit System

Single credit pool that works across multiple features:

```typescript
// Create a credit feature
const creditFeature = await autumn.features.create({
  id: "credits",
  name: "Platform Credits",
  config: {
    usage_type: "continuous_use",
    credit_system: {
      schema: [
        { metered_feature_id: "api_calls", credit_amount: 1 },
        { metered_feature_id: "storage_gb", credit_amount: 10 },
        { metered_feature_id: "compute_hours", credit_amount: 5 }
      ]
    }
  }
});

// Grant credits
const product = await autumn.products.create({
  id: "credit_pack",
  name: "1,000 Platform Credits",
  items: [
    { type: "price", price: 10000, interval: null },
    {
      type: "feature",
      feature_id: "credits",
      included_usage: 1000,
      interval: null
    }
  ]
});

// Track usage (automatically deducts from credit pool)
await autumn.track({
  customer_id: "customer_123",
  feature_id: "api_calls",  // Uses 1 credit
  value: 1
});

await autumn.track({
  customer_id: "customer_123",
  feature_id: "storage_gb",  // Uses 10 credits
  value: 1
});
```

## Frequently Asked Questions

<Accordion title="Can credits be refunded?">
  Yes, you can manually update balances to add credits back:

  ```typescript
  await autumn.balances.update({
    customer_id: "customer_123",
    feature_id: "api_calls",
    add_to_balance: 100  // Refund 100 credits
  });
  ```

  For monetary refunds, you'll need to process those through Stripe separately.
</Accordion>

<Accordion title="Do credits expire automatically?">
  Credits expire based on their configuration:
  - **Recurring credits** (with `interval: "month"`) reset each period
  - **One-time credits** (with `interval: null`) never expire
  - You can manually set expiration dates using the `period_end` field when creating balances
</Accordion>

<Accordion title="Can I transfer credits between customers?">
  Not directly through the API. You would need to:
  1. Deduct credits from customer A
  2. Add credits to customer B

  ```typescript
  // Remove from customer A
  await autumn.balances.update({
    customer_id: "customer_a",
    feature_id: "api_calls",
    add_to_balance: -100
  });

  // Add to customer B
  await autumn.balances.update({
    customer_id: "customer_b",
    feature_id: "api_calls",
    add_to_balance: 100
  });
  ```
</Accordion>

<Accordion title="How do I prevent negative balances?">
  Use the `overage_behavior` parameter when tracking:

  ```typescript
  await autumn.track({
    customer_id: "customer_123",
    feature_id: "api_calls",
    value: 1,
    overage_behavior: "reject"  // Reject if insufficient balance
  });
  ```

  Or check balance before usage:

  ```typescript
  const check = await autumn.check({
    customer_id: "customer_123",
    feature_id: "api_calls"
  });

  if (!check.has_access) {
    return { error: "Insufficient credits" };
  }
  ```
</Accordion>

<Accordion title="What's the difference between credits and prepaid pricing?">
  They're essentially the same - credits are a user-facing term for prepaid balances. The implementation uses the "prepaid" usage model:

  ```typescript
  {
    type: "priced_feature",
    usage_model: "prepaid",  // Deduct from prepaid balance
    included_usage: 1000      // "Credits" granted
  }
  ```
</Accordion>
