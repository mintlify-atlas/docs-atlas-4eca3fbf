## Overview

Seat-based pricing charges customers based on the number of users, team members, or other countable entities. This model scales revenue with team size and is standard for B2B SaaS products.

**Common use cases:**
- Per-user subscriptions (Slack, GitHub, Figma)
- Per-device licenses
- Per-location pricing
- Per-workspace or per-project charges
- Per-API key or per-environment

## How Seat Pricing Works

Seat pricing multiplies a base price by the quantity:

```typescript
{
  type: "price",
  price: 1000,           // $10.00 per seat
  interval: "month"
}

// Customer has 5 seats
// Total: 5 × $10.00 = $50.00/month
```

As customers add or remove seats, billing adjusts automatically with proration.

## Creating Seat-Based Products

<Steps>
  <Step title="Create a product with per-seat pricing">
    Define the price per seat:

    ```typescript
    const teamPlan = await autumn.products.create({
      id: "team_plan",
      name: "Team Plan",
      description: "$10 per user per month",
      items: [
        {
          type: "price",
          price: 1000,         // $10.00 per seat
          interval: "month"
        }
      ]
    });
    ```
  </Step>

  <Step title="Subscribe with initial quantity">
    Specify the number of seats when attaching:

    ```typescript
    await autumn.attach({
      customer_id: "customer_123",
      product_id: "team_plan",
      quantity: 5            // 5 seats
    });
    ```

    This creates a subscription for 5 seats at $50/month.

    <Info>Learn more about the [Attach API](/api-reference/core/attach)</Info>
  </Step>

  <Step title="Update quantity as needed">
    When customers add or remove users:

    ```typescript
    await autumn.attach({
      customer_id: "customer_123",
      product_id: "team_plan",
      quantity: 8            // Increase to 8 seats
    });
    ```

    Billing adjusts automatically with proration.
  </Step>
</Steps>

## Tracking Seats with Entities

For granular seat tracking, use entities to represent individual users:

<Steps>
  <Step title="Create a seat feature">
    Define a feature that represents seats:

    ```typescript
    const seatFeature = await autumn.features.create({
      id: "seats",
      name: "Team Members",
      config: {
        usage_type: "continuous_use"
      }
    });
    ```

    <Info>Learn more about [Features](/concepts/features)</Info>
  </Step>

  <Step title="Create the product with seat tracking">
    Include the seat feature in your product:

    ```typescript
    const product = await autumn.products.create({
      id: "team_plan",
      name: "Team Plan",
      items: [
        {
          type: "priced_feature",
          feature_id: "seats",
          price: 1000,         // $10 per seat
          usage_model: "prepaid",
          interval: "month"
        }
      ]
    });
    ```
  </Step>

  <Step title="Create entities for each user">
    When users join, create an entity:

    ```typescript
    const user = await autumn.entities.create({
      customer_id: "customer_123",
      feature_id: "seats",
      id: "user_alice",
      name: "Alice Smith"
    });
    ```

    Autumn automatically tracks the count and bills accordingly.

    <Info>Learn more about [Entities](/concepts/entities)</Info>
  </Step>

  <Step title="Remove entities when users leave">
    ```typescript
    await autumn.entities.delete({
      customer_id: "customer_123",
      entity_id: "user_alice"
    });
    ```

    Billing adjusts at the next period or immediately with proration.
  </Step>
</Steps>

## Proration for Seat Changes

### Adding Seats Mid-Cycle

When customers add seats during a billing period:

```typescript
// Customer starts with 5 seats on Jan 1
// Base: 5 × $10 = $50/month

// On Jan 15 (halfway through month), add 3 seats
await autumn.attach({
  customer_id: "customer_123",
  product_id: "team_plan",
  quantity: 8  // Now 8 seats
});

// Prorated charge for 3 seats for half a month
// = 3 × $10 × (15/30) = $15
```

**Proration configuration:**

```typescript
{
  type: "price",
  price: 1000,
  interval: "month",
  config: {
    on_increase: "prorate_immediately"  // Charge now (default)
  }
}
```

### Removing Seats Mid-Cycle

When customers remove seats:

```typescript
// Customer has 8 seats
// On Jan 20, reduce to 5 seats
await autumn.attach({
  customer_id: "customer_123",
  product_id: "team_plan",
  quantity: 5
});
```

**Proration configuration:**

```typescript
{
  type: "price",
  price: 1000,
  interval: "month",
  config: {
    on_decrease: "prorate_next_cycle"  // Apply at renewal (default)
  }
}
```

<Tip>
For seat reductions, applying changes at the next renewal prevents mid-cycle credits and maintains access.
</Tip>

## Seat Management Patterns

### Simple Quantity Tracking

Let customers manually set their seat count:

```typescript
// Customer dashboard
async function updateSeats(customerId: string, newQuantity: number) {
  await autumn.attach({
    customer_id: customerId,
    product_id: "team_plan",
    quantity: newQuantity
  });
}
```

### Automatic Seat Tracking

Automatically sync seats with your user database:

```typescript
// When user is created
async function onUserCreated(customerId: string, userId: string, userName: string) {
  // Create entity
  await autumn.entities.create({
    customer_id: customerId,
    feature_id: "seats",
    id: userId,
    name: userName
  });
  
  // Get current seat count
  const customer = await autumn.customers.retrieve({
    customer_id: customerId,
    expand: ["entities"]
  });
  
  const seatCount = customer.entities?.filter(
    e => e.feature_id === "seats"
  ).length || 0;
  
  // Update subscription
  await autumn.attach({
    customer_id: customerId,
    product_id: "team_plan",
    quantity: seatCount
  });
}

// When user is removed
async function onUserRemoved(customerId: string, userId: string) {
  await autumn.entities.delete({
    customer_id: customerId,
    entity_id: userId
  });
  
  // Update seat count
  const customer = await autumn.customers.retrieve({
    customer_id: customerId,
    expand: ["entities"]
  });
  
  const seatCount = customer.entities?.filter(
    e => e.feature_id === "seats"
  ).length || 0;
  
  await autumn.attach({
    customer_id: customerId,
    product_id: "team_plan",
    quantity: seatCount
  });
}
```

### Seat Limits

Enforce maximum seat counts per plan:

```typescript
const starterPlan = await autumn.products.create({
  id: "starter",
  name: "Starter Plan",
  items: [
    {
      type: "priced_feature",
      feature_id: "seats",
      price: 1000,
      usage_model: "prepaid",
      interval: "month",
      usage_limit: 10  // Max 10 seats
    }
  ]
});

// When adding a seat
const customer = await autumn.customers.retrieve({
  customer_id: "customer_123",
  expand: ["entities"]
});

const currentSeats = customer.entities?.filter(
  e => e.feature_id === "seats"
).length || 0;

if (currentSeats >= 10) {
  throw new Error("Seat limit reached. Please upgrade to Pro.");
}

await autumn.entities.create({
  customer_id: "customer_123",
  feature_id: "seats",
  id: "new_user_id"
});
```

## Minimum Seat Requirements

Require a minimum number of seats:

```typescript
const enterprisePlan = await autumn.products.create({
  id: "enterprise",
  name: "Enterprise Plan",
  description: "Minimum 20 seats",
  items: [
    {
      type: "price",
      price: 5000,          // $50 per seat
      interval: "month"
    }
  ]

// When subscribing
const quantity = Math.max(requestedSeats, 20);  // Minimum 20

await autumn.attach({
  customer_id: "customer_123",
  product_id: "enterprise",
  quantity
});
```

## Volume Discounts for Seats

Offer discounts for larger teams using tiered pricing:

```typescript
const volumePlan = await autumn.products.create({
  id: "team_volume",
  name: "Team Plan",
  items: [
    {
      type: "priced_feature",
      feature_id: "seats",
      usage_model: "prepaid",
      interval: "month",
      tiers: [
        {
          to: 10,          // First 10 seats
          amount: 1000     // $10 per seat
        },
        {
          to: 50,          // Seats 11-50
          amount: 900      // $9 per seat
        },
        {
          to: "inf",       // 51+ seats
          amount: 800      // $8 per seat
        }
      ]
    }
  ]
});

// Customer with 75 seats:
// 10 seats × $10 = $100
// 40 seats × $9 = $360
// 25 seats × $8 = $200
// Total: $660/month
```

<Info>Learn more about [Usage-Based Pricing](/pricing-models/usage-based) for tiered pricing details.</Info>

## Checking Seat Usage

Display current seat usage to customers:

```typescript
const customer = await autumn.customers.retrieve({
  customer_id: "customer_123",
  expand: ["entities", "products"]
});

// Get seat count from entities
const seatCount = customer.entities?.filter(
  e => e.feature_id === "seats"
).length || 0;

// Get seat allowance from product
const product = customer.products?.[0];
const seatLimit = product?.items?.find(
  i => i.feature_id === "seats"
)?.usage_limit;

console.log({
  used: seatCount,
  limit: seatLimit || "unlimited",
  remaining: seatLimit ? seatLimit - seatCount : "unlimited"
});
```

## Dashboard Configuration

### Creating a Seat-Based Product

1. Navigate to **Products** → **Create Product**
2. Enter product ID and name (e.g., "team_plan", "Team Plan")
3. Click **Add Item** → **Fixed Price**
   - Set price per seat (e.g., $10.00)
   - Set interval (e.g., "month")
4. Optionally, configure proration:
   - Expand **Advanced Settings**
   - Set **On Increase**: "Prorate Immediately"
   - Set **On Decrease**: "Prorate Next Cycle"
5. Save the product

### Managing Customer Seats

1. Navigate to **Customers** → Select customer
2. Go to **Products** tab
3. Click on the subscription
4. Update **Quantity** field
5. Save (proration applies automatically)

## Common Patterns

### Basic Per-User Pricing

```typescript
const perUserPlan = await autumn.products.create({
  id: "pro_plan",
  name: "Pro Plan",
  items: [
    {
      type: "price",
      price: 1500,           // $15 per user/month
      interval: "month"
    }
  ]
});

// Subscribe with 10 users
await autumn.attach({
  customer_id: "customer_123",
  product_id: "pro_plan",
  quantity: 10             // $150/month total
});
```

### Base + Per-Seat

Charge a base fee plus per-seat charges:

```typescript
const basePlusSeat = await autumn.products.create({
  id: "business_plan",
  name: "Business Plan",
  items: [
    {
      type: "price",
      price: 9900,           // $99 base fee
      interval: "month"
    },
    {
      type: "priced_feature",
      feature_id: "seats",
      price: 1000,           // $10 per additional seat
      included_usage: 5,     // 5 seats included
      usage_model: "prepaid",
      interval: "month"
    }
  ]
});

// Customer with 12 seats:
// Base: $99
// Additional: (12 - 5) × $10 = $70
// Total: $169/month
```

### Active vs. Total Users

Charge only for active users:

```typescript
// Track active users as entities
async function syncActiveSeats(customerId: string) {
  // Get active users from your database
  const activeUsers = await getActiveUsers(customerId);
  
  // Get existing entities
  const customer = await autumn.customers.retrieve({
    customer_id: customerId,
    expand: ["entities"]
  });
  
  const entities = customer.entities?.filter(
    e => e.feature_id === "seats"
  ) || [];
  
  // Remove inactive entities
  for (const entity of entities) {
    if (!activeUsers.find(u => u.id === entity.id)) {
      await autumn.entities.delete({
        customer_id: customerId,
        entity_id: entity.id
      });
    }
  }
  
  // Add new active entities
  for (const user of activeUsers) {
    if (!entities.find(e => e.id === user.id)) {
      await autumn.entities.create({
        customer_id: customerId,
        feature_id: "seats",
        id: user.id,
        name: user.name
      });
    }
  }
  
  // Update subscription quantity
  await autumn.attach({
    customer_id: customerId,
    product_id: "team_plan",
    quantity: activeUsers.length
  });
}

// Run monthly
setInterval(() => syncActiveSeats(customerId), 30 * 24 * 60 * 60 * 1000);
```

## Frequently Asked Questions

<Accordion title="How do I handle seat deactivation vs. deletion?">
  You have two options:

  1. **Remove immediately** - Delete the entity and reduce billing immediately (with proration)
  2. **Deactivate** - Keep the entity but mark it inactive, remove at next renewal

  ```typescript
  // Option 1: Remove immediately
  await autumn.entities.delete({
    customer_id: "customer_123",
    entity_id: "user_id"
  });

  // Option 2: Mark inactive, remove later
  await autumn.entities.update({
    customer_id: "customer_123",
    entity_id: "user_id",
    metadata: { status: "inactive" }
  });
  ```
</Accordion>

<Accordion title="Can I charge different amounts for different seat types?">
  Yes! Create separate features for different seat types:

  ```typescript
  const product = await autumn.products.create({
    id: "team_plan",
    name: "Team Plan",
    items: [
      {
        type: "priced_feature",
        feature_id: "admin_seats",
        price: 2000,  // $20 per admin
        usage_model: "prepaid",
        interval: "month"
      },
      {
        type: "priced_feature",
        feature_id: "member_seats",
        price: 1000,  // $10 per member
        usage_model: "prepaid",
        interval: "month"
      }
    ]
  });
  ```
</Accordion>

<Accordion title="How do I handle seat transfers between users?">
  Seat transfers don't require any billing changes if the total count stays the same. Just update the entity:

  ```typescript
  // Remove old user
  await autumn.entities.delete({
    customer_id: "customer_123",
    entity_id: "old_user_id"
  });

  // Add new user
  await autumn.entities.create({
    customer_id: "customer_123",
    feature_id: "seats",
    id: "new_user_id",
    name: "New User"
  });
  ```
</Accordion>

<Accordion title="What if I want to bundle seats with a base subscription?">
  Use the `included_usage` field to bundle base seats:

  ```typescript
  {
    type: "priced_feature",
    feature_id: "seats",
    included_usage: 5,     // 5 seats included
    price: 1000,           // $10 per additional seat
    usage_model: "prepaid",
    interval: "month"
  }
  ```

  The first 5 seats are free, additional seats are $10 each.
</Accordion>

<Accordion title="How do I show seat usage in my app?">
  Query the customer with expanded entities:

  ```typescript
  const customer = await autumn.customers.retrieve({
    customer_id: "customer_123",
    expand: ["entities", "products"]
  });

  const seats = customer.entities?.filter(
    e => e.feature_id === "seats"
  ) || [];

  const product = customer.products?.[0];
  const seatLimit = product?.items?.find(
    i => i.feature_id === "seats"
  )?.usage_limit;

  // Display in UI
  return {
    used: seats.length,
    limit: seatLimit || Infinity,
    users: seats.map(s => ({ id: s.id, name: s.name }))
  };
  ```
</Accordion>
