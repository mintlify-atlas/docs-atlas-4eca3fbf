## What is Autumn?

Autumn is an open-source layer between Stripe and your application that lets you create any pricing model and embed it with just a few lines of code. Build subscriptions, credit systems, usage-based models, and custom enterprise plans without managing webhooks, upgrades, downgrades, cancellations, or payment failures.

## Why Autumn?

Billing infrastructure gets complex fast. You need permission management, metering, usage limits with cron jobs, and handling of upgrade, downgrade, cancellation, and failed payment states. Race conditions, edge cases, and other bugs will slow you down.

Autumn solves this by decoupling billing logic from your application code. Growing companies iterate on pricing often—raising prices, experimenting with credits, or charging for new features. With Autumn, you can make these changes without database migrations, rebuilding in-app flows, or managing custom pricing.

## How It Works

Autumn abstracts away billing complexity into three core functions:

<Steps>
  <Step title="Define Products and Features">
    Create your products and features in the Autumn dashboard. Configure pricing models, usage limits, and feature access.
  </Step>
  <Step title="Check Access">
    Use `/check` to verify if a customer has access to a feature or sufficient balance.
    
    ```typescript
    const { allowed, balance } = await autumn.check({
      customer_id: "user_123",
      feature_id: "ai_tokens"
    });
    
    if (!allowed) {
      alert("AI limit reached");
    }
    ```
  </Step>
  <Step title="Track Usage">
    Record usage events with `/track` to deduct from balances.
    
    ```typescript
    await autumn.track({
      customer_id: "user_123",
      feature_id: "ai_tokens",
      value: 1312
    });
    ```
  </Step>
  <Step title="Handle Purchases">
    Use `/attach` for all purchase flows—checkouts, upgrades, and downgrades.
    
    ```typescript
    const { checkout_url } = await autumn.attach({
      customer_id: "user_123",
      product_id: "pro"
    });
    
    // Redirect user to checkout_url
    ```
  </Step>
</Steps>

## Real-World Example

Here's how you'd implement a freemium SaaS with AI features:

<CodeGroup>
```typescript React Hook
import { useAutumn } from 'autumn-js/react';

export function AIChat() {
  const autumn = useAutumn();
  
  const handleGenerate = async () => {
    // Check if user has AI tokens
    const { allowed, balance } = await autumn.check({
      customer_id: currentUser.id,
      feature_id: 'ai_tokens',
      required_balance: 100
    });
    
    if (!allowed) {
      // Show upgrade prompt
      showUpgradeModal();
      return;
    }
    
    // Generate AI content
    const result = await generateAI(prompt);
    
    // Track usage
    await autumn.track({
      customer_id: currentUser.id,
      feature_id: 'ai_tokens',
      value: 100
    });
    
    return result;
  };
  
  return (
    <button onClick={handleGenerate}>
      Generate ({balance.remaining} tokens left)
    </button>
  );
}
```

```typescript Node.js
import Autumn from 'autumn-js';

const autumn = new Autumn({
  apiKey: process.env.AUTUMN_SECRET_KEY
});

app.post('/api/generate', async (req, res) => {
  const { prompt, userId } = req.body;
  
  // Check access
  const { allowed, balance } = await autumn.check({
    customer_id: userId,
    feature_id: 'ai_tokens',
    required_balance: 100
  });
  
  if (!allowed) {
    return res.status(403).json({
      error: 'Insufficient AI tokens',
      remaining: balance.remaining
    });
  }
  
  // Generate content
  const result = await generateAI(prompt);
  
  // Track usage
  await autumn.track({
    customer_id: userId,
    feature_id: 'ai_tokens',
    value: 100
  });
  
  res.json({ result, remaining: balance.remaining - 100 });
});
```

```python Python
from autumn import Autumn
import os

autumn = Autumn(api_key=os.getenv('AUTUMN_SECRET_KEY'))

@app.route('/api/generate', methods=['POST'])
def generate():
    data = request.json
    user_id = data['userId']
    prompt = data['prompt']
    
    # Check access
    result = autumn.check(
        customer_id=user_id,
        feature_id='ai_tokens',
        required_balance=100
    )
    
    if not result['allowed']:
        return jsonify({
            'error': 'Insufficient AI tokens',
            'remaining': result['balance']['remaining']
        }), 403
    
    # Generate content
    ai_result = generate_ai(prompt)
    
    # Track usage
    autumn.track(
        customer_id=user_id,
        feature_id='ai_tokens',
        value=100
    )
    
    return jsonify({
        'result': ai_result,
        'remaining': result['balance']['remaining'] - 100
    })
```
