## Welcome to Autumn

Autumn is an open-source billing infrastructure layer that sits between Stripe and your application, enabling you to create any pricing model and embed it with just a couple lines of code.

## Why Autumn?

### Billing Infrastructure Gets Complex Fast

More than just payments: you need permission management, usage metering, consumption limits with cron jobs, and seamless integration with upgrade, downgrade, cancellation, and failed payment states. Race conditions, edge cases, and subtle bugs will slow down your product velocity.

### Decouple Billing from Application Logic

Growing companies iterate on pricing frequently—raising prices, experimenting with credits, or monetizing new features. Without Autumn, each change requires database migrations, rebuilding in-app flows, maintaining internal dashboards for custom pricing, and carefully grandfathering users on legacy plans.

## How It Works

Autumn simplifies your entire billing workflow into three core functions:

### 1. Check Access

Verify if a customer has access to a product, feature, or check their remaining usage:

```typescript
const { check } = useAutumn();

const { data } = await check({ featureId: "ai_tokens" });

if (!data.allowed) {
  alert("AI limit reached");
}
```

### 2. Handle Purchases

One function call for all purchase flows—returns a Stripe Checkout URL or handles upgrades/downgrades automatically:

```tsx
const { attach } = useAutumn();

<button
  onClick={async () => {
    await attach({ productId: "pro" });
  }}
>
  Upgrade to Pro
</button>
```

### 3. Track Usage

Record usage events when customers consume metered features:

```typescript
const { track } = useAutumn();

await track({
  featureId: "ai_tokens",
  value: 1312
});
```

## Key Features

- **Any Pricing Model**: Subscriptions, usage-based, credits, seat-based, hybrid models—build exactly what you need
- **No Webhook Hell**: Autumn handles Stripe webhooks, state transitions, and edge cases automatically
- **Change Pricing Without Code**: Adjust pricing, add features, or create custom enterprise plans through the dashboard
- **Real-Time Usage Metering**: Track consumption with sub-second latency using Redis
- **Automatic Plan Transitions**: Seamless upgrades, downgrades, and cancellations
- **Grandfathering Built-In**: Safely iterate on pricing while maintaining legacy plans
- **Open Source**: Self-host with full control or use our managed cloud service
