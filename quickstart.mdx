## Overview

This guide walks you through creating a simple freemium SaaS with usage-based AI tokens. You'll learn how to:

- Set up Autumn (cloud or self-hosted)
- Create products and features
- Check access to features
- Track usage
- Handle upgrades

By the end, you'll have a working billing system that tracks AI token usage and lets users upgrade to a paid plan.

<Note>
  This quickstart uses the Autumn cloud service for simplicity. For self-hosting, see the [Installation guide](/installation).
</Note>

## Prerequisites

Before you begin, make sure you have:

- A Stripe account ([sign up here](https://stripe.com))
- Node.js 18+ or Python 3.8+ installed
- Basic familiarity with REST APIs

## Step 1: Sign Up for Autumn

<Steps>
  <Step title="Create an account">
    Go to [app.useautumn.com](https://app.useautumn.com) and sign up with your email or Google account.
  </Step>
  
  <Step title="Connect Stripe">
    In the Autumn dashboard, navigate to **Settings** → **Integrations** and connect your Stripe account.
    
    <Warning>
      Use Stripe test mode during development. You can switch to live mode later.
    </Warning>
  </Step>
  
  <Step title="Get your API keys">
    Navigate to **Settings** → **API Keys** and copy your **Secret Key**. You'll need this for API requests.
    
    ```bash
    export AUTUMN_SECRET_KEY="sk_test_..."
    ```
  </Step>
</Steps>

## Step 2: Create Your First Product

<Steps>
  <Step title="Navigate to Products">
    In the dashboard, click **Products** in the sidebar.
  </Step>
  
  <Step title="Create a Free plan">
    Click **Create Product** and configure:
    
    - **Product ID**: `free`
    - **Name**: "Free Plan"
    - **Price**: $0.00 / month
    - Click **Save**
  </Step>
  
  <Step title="Add an AI Tokens feature">
    Within the Free product, click **Add Feature**:
    
    - **Feature ID**: `ai_tokens`
    - **Name**: "AI Tokens"
    - **Type**: Usage-based
    - **Limit**: 1000
    - **Reset**: Monthly
    - Click **Save**
  </Step>
  
  <Step title="Create a Pro plan">
    Click **Create Product** again:
    
    - **Product ID**: `pro`
    - **Name**: "Pro Plan"
    - **Price**: $29.00 / month
    - Click **Save**
  </Step>
  
  <Step title="Add Pro AI Tokens">
    Within the Pro product, add a feature:
    
    - **Feature ID**: `ai_tokens`
    - **Name**: "AI Tokens"
    - **Type**: Usage-based
    - **Limit**: 10000
    - **Reset**: Monthly
  </Step>
</Steps>

<Check>
  You now have two products: a free tier with 1,000 AI tokens per month and a Pro tier with 10,000 tokens per month.
</Check>

## Step 4: Check Feature Access

Let's verify if a user has access to AI tokens:

<CodeGroup>
```typescript Node.js
import Autumn from 'autumn-js';

const autumn = new Autumn({
  apiKey: process.env.AUTUMN_SECRET_KEY
});

// Check if user has AI tokens available
const result = await autumn.check({
  customer_id: 'user_123',
  feature_id: 'ai_tokens',
  required_balance: 100 // Check if they have at least 100 tokens
});

if (result.allowed) {
  console.log(`Access granted. Remaining: ${result.balance.remaining}`);
} else {
  console.log('Insufficient tokens. Please upgrade.');
  console.log(`Current balance: ${result.balance.remaining}`);
}
```

```python Python
from autumn import Autumn
import os

autumn = Autumn(api_key=os.getenv('AUTUMN_SECRET_KEY'))

# Check if user has AI tokens available
result = autumn.check(
    customer_id='user_123',
    feature_id='ai_tokens',
    required_balance=100  # Check if they have at least 100 tokens
)

if result['allowed']:
    print(f"Access granted. Remaining: {result['balance']['remaining']}")
else:
    print('Insufficient tokens. Please upgrade.')
    print(f"Current balance: {result['balance']['remaining']}")
```

```typescript React
import { useAutumn } from 'autumn-js/react';

function AIFeature() {
  const autumn = useAutumn();
  const [result, setResult] = useState(null);
  
  useEffect(() => {
    async function checkAccess() {
      const data = await autumn.check({
        customer_id: 'user_123',
        feature_id: 'ai_tokens',
        required_balance: 100
      });
      setResult(data);
    }
    checkAccess();
  }, []);
  
  if (!result) return <div>Loading...</div>;
  
  return (
    <div>
      {result.allowed ? (
        <div>Access granted. {result.balance.remaining} tokens remaining</div>
      ) : (
        <div>Insufficient tokens. Please upgrade.</div>
      )}
    </div>
  );
}
```
</CodeGroup>

<Info>
  The first time you check access for a new customer, Autumn automatically creates the customer in your database and attaches them to the Free plan.
</Info>


## Step 6: Handle Upgrades

Let users upgrade from Free to Pro:

<CodeGroup>
```typescript Node.js
// Upgrade user to Pro plan
const result = await autumn.attach({
  customer_id: 'user_123',
  product_id: 'pro'
});

if (result.checkout_url) {
  // User needs to complete payment
  console.log('Redirect to:', result.checkout_url);
  // Redirect user to Stripe Checkout
} else {
  // Upgrade complete (e.g., for $0 upgrades)
  console.log('Upgrade successful!');
}
```

```python Python
# Upgrade user to Pro plan
result = autumn.attach(
    customer_id='user_123',
    product_id='pro'
)

if result.get('checkout_url'):
    # User needs to complete payment
    print(f"Redirect to: {result['checkout_url']}")
    # Redirect user to Stripe Checkout
else:
    # Upgrade complete
    print('Upgrade successful!')
```

```typescript React
function UpgradeButton() {
  const autumn = useAutumn();
  
  const handleUpgrade = async () => {
    const result = await autumn.attach({
      customer_id: currentUser.id,
      product_id: 'pro'
    });
    
    if (result.checkout_url) {
      // Redirect to Stripe Checkout
      window.location.href = result.checkout_url;
    } else {
      // Upgrade successful
      alert('Upgrade complete!');
    }
  };
  
  return (
    <button onClick={handleUpgrade}>
      Upgrade to Pro
    </button>
  );
}
```
</CodeGroup>

<Info>
  The `/attach` endpoint handles all purchase flows:
  - New subscriptions (returns a Stripe Checkout URL)
  - Upgrades (prorates automatically)
  - Downgrades (schedules for next billing period)
  - Free plan switches (immediate, no payment required)
</Info>

## Full Example Application

Here's a complete Express.js API with all the billing logic:

```typescript
import express from 'express';
import Autumn from 'autumn-js';

const app = express();
const autumn = new Autumn({
  apiKey: process.env.AUTUMN_SECRET_KEY
});

app.use(express.json());

// Check if user can generate AI content
app.post('/api/ai/check', async (req, res) => {
  const { userId } = req.body;
  
  try {
    const result = await autumn.check({
      customer_id: userId,
      feature_id: 'ai_tokens',
      required_balance: 100
    });
    
    res.json({
      allowed: result.allowed,
      remaining: result.balance.remaining
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// Generate AI content
app.post('/api/ai/generate', async (req, res) => {
  const { userId, prompt } = req.body;
  
  try {
    // Check access
    const { allowed, balance } = await autumn.check({
      customer_id: userId,
      feature_id: 'ai_tokens',
      required_balance: 100
    });
    
    if (!allowed) {
      return res.status(403).json({
        error: 'Insufficient tokens',
        remaining: balance.remaining
      });
    }
    
    // Generate AI content (your logic here)
    const aiResult = await generateAI(prompt);
    
    // Track usage
    await autumn.track({
      customer_id: userId,
      feature_id: 'ai_tokens',
      value: 100
    });
    
    res.json({
      result: aiResult,
      remaining: balance.remaining - 100
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// Upgrade to Pro
app.post('/api/upgrade', async (req, res) => {
  const { userId } = req.body;
  
  try {
    const result = await autumn.attach({
      customer_id: userId,
      product_id: 'pro'
    });
    
    res.json({
      checkout_url: result.checkout_url,
      success: !result.checkout_url // No URL = immediate success
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

app.listen(3000, () => {
  console.log('Server running on port 3000');
});
```
