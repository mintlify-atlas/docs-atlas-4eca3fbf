This guide will walk you through setting up Autumn and implementing your first billing flow. We'll create a simple product, attach it to a customer, and check their access.

## Prerequisites

<CardGroup cols={2}>
  <Card title="Node.js" icon="node-js">
    v18 or higher required
  </Card>
  <Card title="Stripe Account" icon="stripe">
    Free account at stripe.com
  </Card>
</CardGroup>

## Setup

<Steps>
  <Step title="Choose Your Environment">
    You can use Autumn in two ways:

    <Tabs>
      <Tab title="Cloud (Fastest)">
        Sign up for a free account at [app.useautumn.com](https://app.useautumn.com)

        <Note>
          The cloud version is production-ready and maintained by the Autumn team. No setup required.
        </Note>
      </Tab>
      <Tab title="Self-Hosted">
        See the [Self-Hosting Guide](/self-hosting) for detailed instructions on running Autumn locally or on your infrastructure.
      </Tab>
    </Tabs>
  </Step>

  <Step title="Connect Stripe">
    In the Autumn dashboard, navigate to **Developer** → **Configure Stripe** and connect your Stripe account.

    <Warning>
      Use Stripe **test mode** for development. You can switch to live mode later.
    </Warning>
  </Step>

  <Step title="Get Your API Keys">
    In **Developer** → **API Keys**, copy your:
    - **Secret Key** (for server-side API calls)
    - **Public Key** (for client-side SDK)

    <CodeGroup>
    ```bash .env
    # Server-side
    AUTUMN_API_KEY=sk_test_...

    # Client-side (optional)
    NEXT_PUBLIC_AUTUMN_PUBLIC_KEY=pk_test_...
    ```
    </CodeGroup>
  </Step>

  <Step title="Install the SDK">
    <CodeGroup>
    ```bash npm
    npm install autumn-js
    ```

    ```bash yarn
    yarn add autumn-js
    ```

    ```bash pnpm
    pnpm add autumn-js
    ```

    ```bash bun
    bun add autumn-js
    ```
    </CodeGroup>
  </Step>
</Steps>

## Create Your First Product

<Steps>
  <Step title="Create a Product">
    Go to **Products** in the dashboard and click **Create Product**.

    Example configuration:
    - **Name**: "Pro Plan"
    - **ID**: `pro` (you'll use this in code)
    - **Price**: $29/month
    - **Billing Interval**: Monthly
  </Step>

  <Step title="Add Features">
    Click **Add Feature** to create features your product includes:

    <Tabs>
      <Tab title="Boolean Feature">
        ```yaml
        Name: "Priority Support"
        ID: priority_support
        Type: Boolean
        ```
        Users either have it or they don't.
      </Tab>

      <Tab title="Usage Feature">
        ```yaml
        Name: "API Calls"
        ID: api_calls
        Type: Usage
        Limit: 10,000 per month
        Reset: Monthly
        ```
        Track and limit usage over time.
      </Tab>

      <Tab title="Seat-Based Feature">
        ```yaml
        Name: "Team Members"
        ID: team_members
        Type: Seats
        Price: $10 per seat
        ```
        Bill per user or entity.
      </Tab>
    </Tabs>
  </Step>

  <Step title="Publish the Product">
    Click **Publish** to make the product available for purchase.
  </Step>
</Steps>

## Implement Billing in Your App

Now let's integrate Autumn into your application.

### Server-Side Integration

<Tabs>
  <Tab title="Next.js App Router">
    <Steps>
      <Step title="Create the API Handler">
        ```typescript app/api/autumn/[...autumn]/route.ts
        import { autumnHandler } from "autumn-js/next";

        export const { GET, POST } = autumnHandler({
          apiKey: process.env.AUTUMN_API_KEY!,
          getCustomerId: async ({ req }) => {
            // Return your user's ID from your auth system
            // Example with next-auth:
            // const session = await getServerSession();
            // return session?.user?.id;

            return "user_123"; // Replace with real user ID
          },
        });
        ```
      </Step>

      <Step title="Wrap Your App">
        ```tsx app/layout.tsx
        import { AutumnProvider } from "autumn-js/react";

        export default function RootLayout({ children }) {
          return (
            <html>
              <body>
                <AutumnProvider>
                  {children}
                </AutumnProvider>
              </body>
            </html>
          );
        }
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="Express">
    ```typescript server.ts
    import express from "express";
    import { autumnHandler } from "autumn-js/express";

    const app = express();

    app.use("/api/autumn", autumnHandler({
      apiKey: process.env.AUTUMN_API_KEY!,
      getCustomerId: async ({ req }) => {
        // Return user ID from your auth
        return req.user?.id || "user_123";
      },
    }));

    app.listen(3000);
    ```
  </Tab>

  <Tab title="Node.js (Server-Only)">
    ```typescript server.ts
    import { Autumn } from "autumn-js";

    const autumn = new Autumn({
      apiKey: process.env.AUTUMN_API_KEY!,
    });

    // Use autumn.attach(), autumn.check(), autumn.track()
    ```
  </Tab>
</Tabs>

### Client-Side Usage

<Tabs>
  <Tab title="Handle Purchases">
    ```tsx components/UpgradeButton.tsx
    import { useCustomer } from "autumn-js/react";

    export function UpgradeButton() {
      const { attach, loading } = useCustomer();

      const handleUpgrade = async () => {
        const result = await attach({ productId: "pro" });

        if (result.url) {
          // Redirect to Stripe Checkout
          window.location.href = result.url;
        } else if (result.success) {
          // Upgrade completed (no payment needed)
          alert("Successfully upgraded!");
        }
      };

      return (
        <button onClick={handleUpgrade} disabled={loading}>
          Upgrade to Pro
        </button>
      );
    }
    ```
  </Tab>

  <Tab title="Check Access">
    ```tsx components/ProtectedFeature.tsx
    import { useCustomer } from "autumn-js/react";

    export function ProtectedFeature() {
      const { check } = useCustomer();
      const [hasAccess, setHasAccess] = useState(false);

      useEffect(() => {
        async function checkAccess() {
          const result = await check({ featureId: "priority_support" });
          setHasAccess(result.allowed);
        }
        checkAccess();
      }, []);

      if (!hasAccess) {
        return <div>Upgrade to Pro for priority support</div>;
      }

      return <div>Priority support enabled!</div>;
    }
    ```
  </Tab>

  <Tab title="Track Usage">
    ```tsx components/ApiCallTracker.tsx
    import { useCustomer } from "autumn-js/react";

    export function ApiCallTracker() {
      const { track, check } = useCustomer();

      const makeApiCall = async () => {
        // Check if user has remaining API calls
        const access = await check({ featureId: "api_calls" });

        if (!access.allowed) {
          alert("API limit reached. Please upgrade.");
          return;
        }

        // Make your API call...
        await fetch("/api/your-endpoint");

        // Track the usage
        await track({
          featureId: "api_calls",
          value: 1,
        });
      };

      return <button onClick={makeApiCall}>Make API Call</button>;
    }
    ```
  </Tab>
</Tabs>

## Test Your Integration

<Steps>
  <Step title="Create a Test Customer">
    In the dashboard, go to **Customers** → **Create Customer** to create a test customer with the same ID you're using in your code (`user_123`).
  </Step>

  <Step title="Test the Purchase Flow">
    Click your "Upgrade" button and complete the test checkout with Stripe's test card:

    ```
    Card: 4242 4242 4242 4242
    Expiry: Any future date
    CVC: Any 3 digits
    ```
  </Step>

  <Step title="Verify Access">
    After successful checkout, your access check should return `allowed: true`.
  </Step>

  <Step title="Monitor in Dashboard">
    View the customer's active products and usage in **Customers** → select your customer.
  </Step>
</Steps>
