## Overview

The `/cancel` endpoint cancels a customer's subscription to a product. You can choose to cancel immediately or at the end of the current billing period, and optionally provide prorated refunds.

<Note>
  Cancellation is permanent. To temporarily pause access, consider using feature flags or disabling specific features instead.
</Note>

## When to Use

**Use `/cancel` when:**
- Customer requests subscription cancellation
- You need to revoke access to a product
- Implementing self-service cancellation
- Handling failed payments after retry period
- Downgrading customer to free tier

## Authentication

This endpoint requires API key authentication:

```bash
Authorization: Bearer YOUR_API_KEY
```

## Request Body

<ParamField body="customer_id" type="string" required>
  The ID of the customer.

  ```json
  "cus_123"
  ```
</ParamField>

<ParamField body="product_id" type="string" required>
  The ID of the product to cancel.

  ```json
  "pro_plan"
  ```
</ParamField>

<ParamField body="entity_id" type="string">
  The ID of the entity (optional). Use when cancelling entity-scoped subscriptions.

  ```json
  "team_123"
  ```
</ParamField>

<ParamField body="cancel_immediately" type="boolean">
  Whether to cancel the product immediately or at period end.
  
  - `true` - Cancel immediately and revoke access now
  - `false` - Cancel at end of billing period (default)

  ```json
  false
  ```
</ParamField>

<ParamField body="prorate" type="boolean">
  Whether to prorate the cancellation and issue a refund for unused time.
  
  Defaults to `true` if not specified.

  ```json
  true
  ```
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Whether the cancellation was successful.
</ResponseField>

<ResponseField name="customer_id" type="string">
  The ID of the customer.
</ResponseField>

<ResponseField name="product_id" type="string">
  The ID of the canceled product.
</ResponseField>

```typescript React
import { useAutumn } from '@useautumn/react';
import { useState } from 'react';

function CancelSubscription() {
  const autumn = useAutumn();
  const [loading, setLoading] = useState(false);
  const [cancelled, setCancelled] = useState(false);

  const handleCancel = async () => {
    const confirmed = confirm(
      'Are you sure you want to cancel your subscription? ' +
      'You will retain access until the end of your billing period.'
    );

    if (!confirmed) return;

    setLoading(true);
    try {
      const result = await autumn.cancel({
        customer_id: 'cus_123',
        product_id: 'pro_plan',
        cancel_immediately: false,
        prorate: true
      });

      if (result.success) {
        setCancelled(true);
        alert('Subscription cancelled. You will retain access until the end of your billing period.');
      }
    } catch (error) {
      console.error('Cancellation failed:', error);
      alert('Failed to cancel subscription. Please contact support.');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div>
      {!cancelled ? (
        <button 
          onClick={handleCancel} 
          disabled={loading}
          className="cancel-button"
        >
          {loading ? 'Cancelling...' : 'Cancel Subscription'}
        </button>
      ) : (
        <div className="cancelled-message">
          <p>Your subscription has been cancelled.</p>
          <p>Access will continue until the end of your billing period.</p>
        </div>
      )}
    </div>
  );
}
```

## Cancellation Behavior

### Cancel at Period End (cancel_immediately: false)

**Default behavior** - Most customer-friendly option:

- Subscription is marked for cancellation
- Customer retains full access until period end
- No refund issued (they paid for full period)
- Access automatically revokes when period expires

```typescript
await autumn.cancel({
  customer_id: 'cus_123',
  product_id: 'pro_plan',
  cancel_immediately: false
});
```

**Use when:**
- Customer initiates cancellation
- You want to provide full value for payment
- Reducing churn (customer might change mind)

### Cancel Immediately (cancel_immediately: true)

**Immediate cancellation:**

- Subscription cancelled immediately
- Access revoked right away
- Prorated refund issued if `prorate: true`
- Customer loses access to features instantly

```typescript
await autumn.cancel({
  customer_id: 'cus_123',
  product_id: 'pro_plan',
  cancel_immediately: true,
  prorate: true
});
```

**Use when:**
- Payment failed after retry period
- Account suspension required
- Customer explicitly requests immediate cancellation with refund
- Fraud or policy violation

### Proration Behavior

When `prorate: true` and `cancel_immediately: true`:

- Calculates unused time in billing period
- Issues prorated credit/refund to customer
- Creates negative invoice line items

Example: Customer cancels on day 10 of 30-day cycle:
- Paid: $30.00
- Used: $10.00 (10/30 days)
- Refund: $20.00 (20/30 days unused)

## Best Practices

### Confirm Before Cancellation

```typescript
const confirmCancellation = async () => {
  const result = await showModal({
    title: 'Cancel Subscription?',
    message: 'You will retain access until the end of your billing period.',
    options: [
      { label: 'Keep Subscription', value: false },
      { label: 'Cancel at Period End', value: 'period_end' },
      { label: 'Cancel Immediately', value: 'immediate' }
    ]
  });

  if (result === 'period_end') {
    await autumn.cancel({
      customer_id: 'cus_123',
      product_id: 'pro_plan',
      cancel_immediately: false
    });
  } else if (result === 'immediate') {
    await autumn.cancel({
      customer_id: 'cus_123',
      product_id: 'pro_plan',
      cancel_immediately: true,
      prorate: true
    });
  }
};
```

## Reactivating Cancelled Subscriptions

If a subscription was cancelled but hasn't ended yet, you can reactivate it by calling `/attach` again:

```typescript
// Reactivate before period end
const result = await autumn.attach({
  customer_id: 'cus_123',
  product_id: 'pro_plan'
});
```

## Error Handling

<ResponseField name="error" type="object">
  <Expandable title="Error Object">
    <ResponseField name="code" type="string">
      Error code identifying the type of error.
      
      Common error codes:
      - `customer_not_found` - The specified customer does not exist
      - `product_not_found` - The specified product does not exist
      - `not_subscribed` - Customer is not subscribed to this product
      - `already_cancelled` - Subscription is already cancelled
      - `stripe_error` - Error from Stripe API
    </ResponseField>
    <ResponseField name="message" type="string">
      Human-readable error message.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example Error Response

```json
{
  "error": {
    "code": "not_subscribed",
    "message": "Customer is not subscribed to product 'pro_plan'"
  }
}
```

### Handling Errors

```typescript
try {
  const result = await autumn.cancel({
    customer_id: 'cus_123',
    product_id: 'pro_plan'
  });
} catch (error) {
  if (error.code === 'not_subscribed') {
    console.log('Customer is not subscribed to this product');
  } else if (error.code === 'already_cancelled') {
    console.log('Subscription is already cancelled');
  } else {
    console.error('Cancellation failed:', error);
  }
}
```
