## Overview

The billing portal endpoint creates a secure Stripe-hosted session where customers can self-manage their subscriptions, payment methods, and view billing history. This provides a complete self-service billing experience without building custom UI.

<Note>
  The billing portal is hosted by Stripe and provides a secure, PCI-compliant interface for customers to manage their own billing information.
</Note>

## When to Use

**Use billing portal when:**
- Providing self-service subscription management
- Allowing customers to update payment methods
- Letting customers view invoices and payment history
- Enabling subscription cancellation
- Reducing support burden for billing inquiries

## Authentication

This endpoint requires API key authentication:

```bash
Authorization: Bearer YOUR_API_KEY
```

## Path Parameters

<ParamField path="customer_id" type="string" required>
  The customer's unique identifier. The customer must have a linked Stripe account.

  ```
  cus_123
  ```
</ParamField>

## Request Body

<ParamField body="configuration_id" type="string">
  Stripe billing portal configuration ID. Create configurations in your [Stripe Dashboard](https://dashboard.stripe.com/settings/billing/portal) to customize the portal's appearance and functionality.

  If not provided, Autumn will use the default portal configuration.

  ```json
  "bpc_1ABC123"
  ```
</ParamField>

<ParamField body="return_url" type="string">
  URL to redirect the customer to when they click the back button in the billing portal.

  ```json
  "https://example.com/account/billing"
  ```
</ParamField>

## Response

<ResponseField name="customer_id" type="string" nullable>
  The customer's unique identifier (echoed from the request).
</ResponseField>

<ResponseField name="url" type="string">
  The Stripe billing portal session URL. Redirect your customer to this URL to allow them to manage their billing information.

  **Important**: This URL expires after a short period (typically 1 hour). Generate a new URL each time a customer wants to access the portal.
</ResponseField>

## Portal Features

The Stripe billing portal allows customers to:

### Payment Methods
- Add new payment methods (credit/debit cards)
- Update existing payment methods
- Set default payment method
- Remove payment methods

### Subscriptions
- View active subscriptions
- Upgrade or downgrade plans (if configured)
- Cancel subscriptions (if configured)
- View upcoming renewals and amounts

### Invoices
- View past invoices
- Download invoice PDFs
- View payment receipts
- Access invoice history

### Billing Information
- Update billing email
- View billing address
- Update billing details

## Portal Configuration

Configure your billing portal in the [Stripe Dashboard](https://dashboard.stripe.com/settings/billing/portal):

### Customer Access Controls

```typescript
// Use different configurations for different customer types
const getPor talConfig = (customerType: string) => {
  if (customerType === 'enterprise') {
    return 'bpc_enterprise_config'; // Full control
  } else if (customerType === 'pro') {
    return 'bpc_pro_config'; // Can manage payment, can't cancel
  } else {
    return 'bpc_basic_config'; // Read-only
  }
};

const session = await autumn.billingPortal({
  customer_id: 'cus_123',
  configuration_id: getPortalConfig(customer.type),
  return_url: 'https://example.com/account'
});
```

### Configuration Options

In your Stripe Dashboard, configure:

- **Subscription management** - Allow customers to cancel, pause, or change plans
- **Payment method updates** - Enable adding/removing payment methods
- **Invoice history** - Set how many invoices are visible
- **Branding** - Customize colors, logos, and icons
- **Business information** - Set company name, support details
- **Features** - Enable/disable specific portal features

### Handle Missing Stripe Integration

```typescript
const openBillingPortalSafely = async (customerId: string) => {
  try {
    const session = await autumn.billingPortal({
      customer_id: customerId,
      return_url: 'https://example.com/account'
    });
    window.location.href = session.url;
  } catch (error) {
    if (error.message?.includes('no Stripe ID')) {
      // Customer doesn't have Stripe ID yet
      alert('Please add a payment method first.');
      
      // Redirect to payment setup
      const setupSession = await autumn.setupPayment({
        customer_id: customerId,
        success_url: 'https://example.com/account'
      });
      window.location.href = setupSession.url;
    } else {
      throw error;
    }
  }
};
```

### Generate Fresh URLs

```typescript

const cachedUrl = await getCachedPortalUrl();

// ✅ Generate fresh URL every time
const session = await autumn.billingPortal({
  customer_id: 'cus_123',
  return_url: 'https://example.com/account'
```

### Handle Portal Events via Webhooks

```typescript
app.post('/webhooks/stripe', async (req, res) => {
  const event = req.body;

  switch (event.type) {
    case 'customer.subscription.updated':
      // Customer changed their subscription in portal
      await handleSubscriptionChange(event.data);
      break;

    case 'payment_method.attached':
      // Customer added payment method in portal
      await handlePaymentMethodAdded(event.data);
      break;

    case 'customer.subscription.deleted':
      // Customer cancelled in portal
      await handleSubscriptionCancelled(event.data);
      break;
  }

  res.json({ received: true });
});
```

## Security Considerations

### Server-Side Generation

For security, generate portal URLs on your server:

```typescript
// Client-side
const openPortal = async () => {
  const response = await fetch('/api/billing-portal', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${userToken}` }
  });
  
  const { url } = await response.json();
  window.location.href = url;
};

// Server-side
app.post('/api/billing-portal', authenticateUser, async (req, res) => {
  const session = await autumn.billingPortal({
    customer_id: req.user.id,
    return_url: req.body.return_url
  });

  res.json({ url: session.url });
});
```

## Error Handling

<ResponseField name="error" type="object">
  <Expandable title="Error Object">
    <ResponseField name="code" type="string">
      Error code identifying the type of error.
      
      Common error codes:
      - `customer_not_found` - The specified customer does not exist
      - `no_stripe_customer` - Customer does not have a Stripe ID
      - `stripe_error` - Error from Stripe API
      - `invalid_configuration` - Invalid configuration_id
    </ResponseField>
    <ResponseField name="message" type="string">
      Human-readable error message.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example Error Response

```json
{
  "error": {
    "code": "no_stripe_customer",
    "message": "Customer has no Stripe ID. Please create a payment method first."
  }
}
```

### Handling Errors

```typescript
try {
  const session = await autumn.billingPortal({
    customer_id: 'cus_123',
    return_url: 'https://example.com/account'
  });
  window.location.href = session.url;
} catch (error) {
  if (error.code === 'no_stripe_customer') {
    // Redirect to payment setup instead
    const setupSession = await autumn.setupPayment({
      customer_id: 'cus_123',
      success_url: 'https://example.com/account'
    });
    window.location.href = setupSession.url;
  } else {
    console.error('Failed to open portal:', error);
    showError('Unable to open billing portal');
  }
}
```
