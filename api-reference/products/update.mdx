---
title: "Update Product"
api: "POST /plans/{plan_id}"
---

Updates a product (plan). By default, this creates a new version of the product, preserving existing subscriptions on older versions.

<Warning>
  Updating a product creates a **new version** by default. Existing subscriptions remain on their current version unless explicitly migrated.
</Warning>

## Path Parameters

<ParamField path="plan_id" type="string" required>
  The unique identifier of the product to update.
</ParamField>

## Query Parameters

<ParamField query="version" type="number">
  Update a specific version. If omitted, creates a new version based on the latest.
</ParamField>

<ParamField query="upsert" type="boolean">
  If `true`, creates the product if it doesn't exist. Otherwise returns an error for non-existent products.
</ParamField>

<ParamField query="disable_version" type="boolean">
  If `true`, updates the existing version instead of creating a new version. Use with caution as this affects all active subscriptions.
</ParamField>

## Request Body

All fields are optional. Only include fields you want to update.

<ParamField body="name" type="string">
  Update the display name.
</ParamField>

<ParamField body="description" type="string">
  Update the description.
</ParamField>

<ParamField body="group" type="string">
  Update the grouping identifier.
</ParamField>

<ParamField body="add_on" type="boolean">
  Change whether this is an add-on.
</ParamField>

<ParamField body="auto_enable" type="boolean">
  Change auto-enable behavior.
</ParamField>

<ParamField body="archived" type="boolean">
  Archive or unarchive the product. Archived products can't be attached to new customers.
</ParamField>

<ParamField body="price" type="object">
  Update the base subscription price. See [Create Product](/api-reference/products/create#request-body) for schema.
</ParamField>

<ParamField body="items" type="array">
  Update the features included in this product. See [Create Product](/api-reference/products/create#request-body) for schema.
</ParamField>

<ParamField body="free_trial" type="object">
  Update free trial configuration. See [Create Product](/api-reference/products/create#request-body) for schema.
</ParamField>

## Response

Returns the updated [Product](/api-reference/products/list#product-object) object.

## Versioning Behavior

### Default: Create New Version

By default, updates create a new version:

```javascript
// This creates version 2 of the product
await autumn.plans.update('plan_starter', {
  price: {
    amount: 3900,  // Increase price
    interval: 'month'
  }
});

// Existing customers remain on version 1
// New customers get version 2
```

### Update Existing Version

Use `disable_version: true` to modify the current version:

```javascript
// This updates version 1 for all subscribers
await autumn.plans.update('plan_starter', 
  {
    description: 'Updated description'
  },
  {
    disable_version: true
  }
);
```

<Warning>
  When `disable_version: true`, changes affect **all active subscriptions** immediately. Use this carefully, typically only for non-breaking changes like descriptions or display text.
</Warning>

### Update Specific Version

Update a specific version using the `version` query parameter:

```javascript
// Update version 2 specifically
await autumn.plans.update('plan_starter',
  {
    name: 'Starter Plan (Updated)'
  },
  {
    version: 2,
    disable_version: true
  }
);
```

## Common Update Patterns

### Change Pricing

Create a new version with updated pricing:

```javascript
await autumn.plans.update('plan_pro', {
  price: {
    amount: 12900,  // Was $99, now $129
    interval: 'month'
  }
});
```

### Add or Modify Features

Update included limits or add new features:

```javascript
await autumn.plans.update('plan_starter', {
  items: [
    {
      feature_id: 'api_calls',
      included: 20000  // Increase from 10,000
    },
    {
      feature_id: 'webhooks',
      included: 100,
      unlimited: false
    }
  ]
});
```

### Update Free Trial

Modify trial terms:

```javascript
await autumn.plans.update('plan_starter', {
  free_trial: {
    duration_length: 30,  // Extend to 30 days
    duration_type: 'day',
    card_required: true   // Now require card
  }
});
```

### Archive Product

Prevent new subscriptions while keeping existing ones:

```javascript
await autumn.plans.update('plan_legacy', {
  archived: true
});
```
