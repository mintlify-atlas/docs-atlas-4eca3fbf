---
title: "Update Customer"
api: "POST /customers/:customer_id"
---

Updates the specified customer by setting the values of the parameters passed. Any parameters not provided will be left unchanged.

<Note>
  This endpoint also accepts `PATCH` requests with the same behavior.
</Note>

## Path Parameters

<ParamField path="customer_id" type="string" required>
  The unique identifier of the customer to update.
</ParamField>

## Request Body

<ParamField body="id" type="string">
  New unique identifier for the customer. Must not already exist for another customer.
  
  - Cannot contain @ symbol, spaces, or periods
  - Only letters, numbers, underscores, and hyphens are allowed
  - Cannot be an empty string or null
</ParamField>

<ParamField body="name" type="string">
  Customer's name.
</ParamField>

<ParamField body="email" type="string">
  Customer's email address. Must be a valid email format.
</ParamField>

<ParamField body="fingerprint" type="string">
  Unique identifier (e.g., device serial number) to detect duplicate customers.
</ParamField>

<ParamField body="metadata" type="object">
  Additional metadata for the customer. Pass `null` for a key to delete that metadata field.
</ParamField>

<ParamField body="stripe_id" type="string">
  New Stripe customer ID to associate with this customer. The Stripe customer must exist.
</ParamField>

<ParamField body="send_email_receipts" type="boolean">
  Whether to send email receipts to this customer.
</ParamField>

## Query Parameters

<ParamField query="expand" type="array">
  Expandable fields to include in the response. See [Retrieve Customer](/api-reference/customers/get#expandable-fields) for available fields.
</ParamField>

## Response

Returns the updated [Customer](/api-reference/customers/get#response) object if the update succeeded.

<ResponseField name="id" type="string">
  Your unique identifier for the customer (may be updated).
</ResponseField>

<ResponseField name="name" type="string">
  Customer's name.
</ResponseField>

<ResponseField name="email" type="string">
  Customer's email address.
</ResponseField>

<ResponseField name="created_at" type="number">
  Unix timestamp when the customer was created.
</ResponseField>

<ResponseField name="fingerprint" type="string">
  Unique device identifier for the customer.
</ResponseField>

<ResponseField name="stripe_id" type="string">
  Associated Stripe customer ID.
</ResponseField>

<ResponseField name="env" type="string">
  Environment where the customer exists.
</ResponseField>

<ResponseField name="metadata" type="object">
  Additional metadata stored for the customer.
</ResponseField>

<ResponseField name="send_email_receipts" type="boolean">
  Whether email receipts are enabled for this customer.
</ResponseField>

<ResponseField name="subscriptions" type="array">
  Array of active subscriptions.
</ResponseField>

<ResponseField name="scheduled_subscriptions" type="array">
  Array of scheduled subscriptions.
</ResponseField>

<ResponseField name="balances" type="object">
  Object mapping feature IDs to balance objects.
</ResponseField>

## Metadata Updates

To delete a metadata key, set its value to `null` in the request:

```json
{
  "metadata": {
    "old_key": null,
    "new_key": "new_value"
  }
}
```

## Stripe Synchronization

When you update a customer's `name` or `email`, Autumn automatically synchronizes these changes to the associated Stripe customer (if one exists).

<RequestExample>
```bash cURL
curl -X POST https://api.autumn.com/v1/customers/user_12345 \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Jane Doe",
    "email": "jane.doe@example.com",
    "metadata": {
      "user_tier": "enterprise"
    }
  }'
```

```bash cURL - Update customer ID
curl -X POST https://api.autumn.com/v1/customers/user_12345 \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "user_new_id"
  }'
```

```javascript JavaScript
const customer = await autumn.customers.update('user_12345', {
  name: 'Jane Doe',
  email: 'jane.doe@example.com',
  metadata: {
    user_tier: 'enterprise'
  }
});
```

```python Python
customer = autumn.customers.update(
    'user_12345',
    name='Jane Doe',
    email='jane.doe@example.com',
    metadata={
        'user_tier': 'enterprise'
    }
)
```
</RequestExample>
